# Badges

Most badges celebrate climbing milestones: your first session or send, ascent totals, grades and more. These use the dates of the relevant climbs in your logbook. Importing an older climb can therefore move a climbing milestone earlier.

**First Moves** celebrates bringing your logbook into Crag Stats. Its date is the first successful import or sync containing at least one ascent, and its count is saved with that import. Later syncs and imported older climbs do not move it. It has no link to an individual climb. Import timestamps use the site's display time zone.

Earlier versions did not save the first-import date and incorrectly displayed the earliest climb's date. Existing logbooks show **Import date unknown** until the owner enters the original date in **Settings → First Moves badge**. Use the date you first imported or synced your logbook, not your first climbing day. A later sync does not fill an unknown historical date with today's date. The count for an older installation uses the available logbook count when the milestone is first recorded.

The same Settings control can correct a date entered by mistake. Wiping local data resets this milestone along with the logbook; the next successful non-empty import starts a new one.
