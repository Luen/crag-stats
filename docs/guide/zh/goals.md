# 目标

目标功能可将 theCrag 记录本中的目标转化为仪表板和**目标**页面上的进度条。高度和攀爬天数目标按线性比例填充。**难度**目标使用近似的**金字塔准备度**模型，因此比目标低一个等级的状态不再看起来像是快要完成了。

## 目标类型

| 类型        | “完成”的定义                  | 进度条         |
| --------- | ------------------------ | ----------- |
| **年度难度**  | 在目标年份内完攀一条难度分数达到或超过目标的线路 | 金字塔准备度（见下文） |
| **今年的高度** | 该年份攀爬的总米数                | 线性：米数 ÷ 目标  |
| **本月天数**  | 当前日历月中独立的攀爬天数            | 线性：天数 ÷ 目标  |
| **自定义**   | 由你标记为完成                  | 手动（无自动填充）   |

场地范围（户外 / 室内 / 不限）决定哪些攀登记录计入统计。等级目标默认为**户外**。

高度目标始终**以米为单位存储**。创建表单会要求以你选择的高度单位（米或英尺）输入目标，并在保存前转换英尺；进度和目标标签也会遵循该单位。之后切换单位会更改目标的标签，但不会改变存储的目标值。参见[显示设置](/docs/display-settings)。

等级目标保留其**线路**或**抱石**量表。目标和进度标签遵循设置中相应的等级系统；更改显示系统不会改变目标值或百分比。建议目标的标题也遵循设置，而自定义标题保持输入时的原样。在目标的**难度偏好**中，你可以选择其量表以及是否使用自动标题。

如果目标显示**需要等级量表**，则在所有者选择**线路**或**抱石**之前，其进度不可用。它的标题和保存的目标值会被保留；标题中提到的等级并不能决定其量表。

## 等级准备度

等级目标要求在目标年份内有一次**完攀难度 ≥ 目标**（使用标准分数，线路通常为 Ewbank，抱石为 V 等级）。进度条**不是** `best send ÷ target` —— 那种算法会让 22→23 看起来已完成 ~96%，而实际上仍需完攀一条难度 23 的线路。

相反，该模型会询问你在目标 **N** 之下构建的金字塔有多稳固，以及你在接近该等级的线路上投入了多少：

1. 当你符合条件的最高完成等级已经 ≥ N 时，为 **已完成 (100%)**。
2. 当你在 N−1 级别有完成记录 (~35%) 或仅在 N−2 级别有记录 (~10%) 时，为 **基础**。
3. **金字塔填充**来自在这些区间内完成的不同线路 —— 大致需要 **2 条 N−1 的线路**和 **4 条 N−2 的线路**（分别最多增加约 +20% 和 +25%）。
4. **尝试填充**来自有效分数 **≥ N−1** 的未完攀记录（磕线）—— 最多增加约 +20%，并按**预计投入时间调整**大致所需尝试次数，因此短期项目的每次尝试会比长期项目推进更多进度。
5. **基础模型上限为 94%。** 第一次符合条件的练习建立基准；之后每个在 ≥ N−1 级别有练习记录的独立攀爬日都会增加一点准备度，最高可达 99%。只有符合条件的完成记录才能达到 100%。同一天的多条线路或多次尝试计为一次练习；缺失、无效和未来的日期不计入。训练日的计入规则遵循目标年份和场地筛选，不会改变高度或攀登天数目标的比例。

完成证据使用与完成情况相同的年份和场地筛选：**有效等级**（多段线路中爬过的最难一段）以及每个金字塔区间内的**不同线路**（同一条线路的重复完成仅计入一次）。尝试会计入每一次符合条件的练习记录（同一条线路的重复尝试仍会推动进度条）。

进度行会显示你的最高完攀难度、N−1 / N−2 的线路数、已有的尝试数据，以及简短的预计投入时间提示：

| 距离目标的差距       | 提示 | 软性尝试需求（≈ 填满尝试区间） |
| ------------- | -- | ---------------- |
| 1 个等级         | 短期 | ~15 次尝试          |
| 2 个等级         | 中期 | ~35 次尝试          |
| 差距更大 / 尚无完攀记录 | 长期 | ~75 次尝试          |

## 建议的下一个等级

在**目标**页面上，如果你在过去**两年**内有室外完成记录，Crag Stats 可能会提供一个软性建议：以你最难的室外完成记录（线路和/或抱石，分开计算）为基础，设定今年冲击**下一个等级步进**的目标（例如 V5 → V6, 25 → 26）。在你点击**添加目标**之前，建议功能绝不会自动创建目标。如果你已经在追踪该年度的室外目标，该标签会显示**已在追踪中**。

## 你将看到的内容

- **仪表盘**“活动目标”卡片：最多显示几个开启的目标，并附有相同的百分比和标签。
- **目标**页面：可选的建议下一等级标签、完整的“活动中”/“已达成”列表、创建/编辑功能，以及针对等级目标的相同准备度文案。

## 注意事项

- **近似值。** 软金字塔数值是教练的经验法则，而非对你一定能完成 N 的预测。
- **同系统评分。** 支撑区间为分数范围 [N−1, N) 和 [N−2, N−1)，因此低于目标的带分数完成记录仍能提供支撑。分数使用目标的标准分数；混合等级系统不会在进度条内进行转换。
- **量表、年份和场地。** 线路和 V-scale 证据绝不混用。目标年份之外的旧记录或错误的场地不会增加准备度。使用 V 等级的 DWS 和 Highball 计入抱石目标，这取决于所使用的等级系统而非装备类型。
- **尝试次数为近似值。** 我们只能看到已记录且难度 ≥ N−1 的未完攀记录——无法统计未定级项目上的每一次尝试。
- **自定义目标**绝不会从记录本中自动填充。

高度和天数目标保持简单的线性比例，因此完成了一半的公里数或月份仍显示为进度过半。
