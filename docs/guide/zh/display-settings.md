# 显示设置

**设置 → 显示与可见性** 设定了日期和计量单位在整个网站上的显示方式。这些选项适用于每一位访问者，而不仅仅是所有者的浏览器，并在下一次页面加载时生效。

## 日期格式

| 选项             | 示例         |
| -------------- | ---------- |
| **自动**         | 2026年十月27日 |
| **DD/MM/YYYY** | 27/10/2026 |
| **MM/DD/YYYY** | 10/27/2026 |
| **YYYY-MM-DD** | 2026-10-27 |

**自动** 遵循网站的显示语言区域 (`DISPLAY_LOCALE`)，因此无需额外配置即可让大多数访问者自然阅读。

该格式会更改仪表板、攀登日志、天气页面、徽章、目标、里程碑和图表上显示的日历日期。过滤链接、`datetime` 属性、图表数据和 URL 参数保留其 ISO `YYYY-MM-DD` 值，因此共享链接始终指向同一天。

## 计量单位

每种计量方式都有自己的设置，因此你可以混合搭配：

| 计量项     | 选项                 |
| ------- | ------------------ |
| **高度**  | 米 (m), 英尺 (ft)     |
| **距离**  | 公里 (km), 英里 (mi)   |
| **温度**  | 摄氏度 (°C), 华氏度 (°F) |
| **风速**  | km/h、mph           |
| **降水量** | 毫米 (mm), 英寸 (in)   |

预设可以一次性填充所有五项：

- **公制**：米、公里、摄氏度、公里/小时和毫米。
- **英制（美国）**：英尺、英里、华氏度、mph 和英寸。
- **英式（混合）**：米、英里、摄氏度、mph 和毫米。

预设仅是一种快捷方式：之后更改单个单位会产生自定义组合，设置表单会显示存储的具体数值。

## 保持公制的部分

数据库始终以米为单位存储高度、公里为单位存储距离、°C 为单位存储温度、km/h 为单位存储风速、毫米为单位存储降水量。转换仅在页面渲染时发生，因此切换单位绝不会重写你的攀登日志、目标或导入的数据。

- **CSV 导出** 保留其标准的公制列。
- **徽章阈值**（高度指标、高温、严寒、降雨、风速等）以公制定义。只有文字表述会转换，例如 **热浪来袭** 在公制下显示为“35°C 或更高”，在华氏度下显示为“95°F 或更高”。无论采用哪种单位，同样的攀登活动都会获得同样的徽章。
- **天气过滤器**，例如攀登日志中的高温、严寒、雨、雪和风速过滤器，保持其公制阈值。
- **显示转换是经过舍入的**，因此以英尺、英里或英寸显示的数值是近似值，而非第二个存储的读数。

## 一次性覆盖

仪表板接受 `?units=metric`、`?units=imperial` 或 `?units=uk` 参数，用于预览预设而无需保存。单个参数一次覆盖一个计量项：`unitHeight`、`unitDistance`、`unitTemp`、`unitWind` 和 `unitPrecip`（例如 `?unitTemp=fahrenheit&unitWind=mph`）。这些仅适用于该次页面加载，不会更改设置。

## 设置生效的位置

日期和单位选择将应用到仪表板、攀登日志、活动日历、训练负荷、天气页面、分区、攀爬地图、目标、徽章、里程碑、嵌入卡片以及离线快照。难度等级系统是独立的：请参阅 [难度等级](/docs/grades)。
