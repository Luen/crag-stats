# 首升

“**首升**”卡片统计了你完成首升（**FA**）或首次自由攀登（**FFA**）的路线和抱石线路。当缓存了路线历史记录时，它还会显示有多少条路线将你列为**定线员**（打眼/定线）。

## 你需要什么

- **管理员登录** — 如果设置了 `APP_PASSWORD`，请登录以便打开“设置”并使用日志中的“**标记 FA**” / “**FFA**”功能。访客在至少有一条路线被标记后即可看到卡片和徽章，但无法自行添加标记。
- **可选的路线数据导入** — 如果你希望 Crag Stats 从 theCrag 的公开路线历史记录中自动标记 FA 和 FFA，请在服务器上设置 `ROUTE_DATA_IMPORT=true`（见下文）。手动标记和导入都会写入同一个 `first_ascents` 表；两者都不依赖于私人笔记。
- **私人笔记与之无关** — **设置 → 显示私人笔记**仅控制你的**攀登评论**是否出现在 `/logbook`（以及搜索结果）中。它不会限制首升卡片、FA/FFA 徽章、里程碑或路线数据导入。

## 标记一次首升

theCrag 将首次攀登记录在每条线路的**历史**中（线路页面上的 FA / FFA 条目），而非作为攀登记录类型。它的日志 API 不返回路线历史记录，因此正常的同步无法看到它们。你可以自行标记它们，或者开启下方的可选导入功能。

### 手动标记

1. 打开**攀登日志**并找到该路线的任何一次攀登记录。
2. 悬停在该行（或通过 Tab 键选中）并点击“**标记 FA**”或“**FFA**”。
3. 点击“**取消标记**”以撤销。

只有能打开“设置”的人才能标记 FA：如果没有设置 `APP_PASSWORD`，则任何人都可以；否则仅限登录后操作。访客可以看到 FA 徽章和卡片，但看不到按钮。

标记是针对 theCrag 的路线 ID 存储的，因此在重新同步后依然存在。如果 theCrag 上该路线的所有攀登记录都被删除，它会从卡片中消失；如果你再次记录该路线，它会重新出现。**设置 → 清空**将删除所有标记。

### 过滤攀登日志

在**攀登日志**中，使用“**首攀标记**”控件来仅显示你的 FA、FFA、两者或尚未标记的攀登 (`?fa=FA|FFA|any|none`)。如果启用了路线数据导入，管理员还会看到“**尚未检查历史记录**” (`?history=pending`)，其中列出了导入器尚未获取的攀登。

### 从路线历史记录导入（可选，默认关闭）

如果你的服务器管理员开启了此项（`ROUTE_DATA_IMPORT=true`；旧版本称为 `ROUTE_HISTORY_IMPORT`，现已不再读取，请重命名并重启），Crag Stats 会在后台从 theCrag 读取每条日志路线的公开历史记录，并标记署名为你的 FA 和 FFA。

- **仅限署名为你的 theCrag 用户名** (`@yourlogin`) 的条目才有效。纯文本姓名会被忽略，因为它们太容易混淆。 API 同步会保存该登录名；如果你的日志来自 CSV 上传，请设置 `THECRAG_USERNAME` 以便导入程序知道哪些条目属于你。
- **你的选择优先。** 你设置的标记将保持原样，你取消标记的路线也将保持未标记状态。**设置 → 导入路线数据 → 重新应用**可以覆盖以上任一情况，使用已保存的历史记录，而无需再次请求 theCrag。
- **对 theCrag 友好。** 默认情况下，每条路线仅检查**一次**（下文将介绍可选的定期数据更新），每次运行最多检查 **100 条路线**，且每秒仅发一次请求。运行会在每次攀登日志同步或 CSV 上传后、按后台导入计划（`IMPORT_CRON`，默认每天一次）、应用重启且仍有路线等待处理时（例如升级后），或当您点击**立即检查下 100 条路线**时触发。如果 theCrag 拒绝请求，导入将暂停至少一天。
- “设置”会显示目前为止已检查了多少条你的路线。通过每日同步，几百条路线需要几周时间；点击按钮可以加快这一过程。

仅保存公开的路线历史记录，绝不会保存你的私人攀登笔记。**设置 → 清空**会将其随同你的标记一并删除。

## 卡片显示的内容

当卡片包含导入的 FA/FFA 或定线员署名时，其页脚会注明来源为 theCrag 路线历史。即使随后禁用了导入，该信息也会随保存的署名显示。手动标记无需注明来源；同时包含手动标记和导入数据时，仍保留线路历史的来源说明。

- **计数：** 有多少条路线被归功为 FA 或 FFA，来自手动标记或路线数据导入（公开路线历史）。当你有 FFA 时，它还会显示 FA / FFA 的细分。
- **定线路线：** 缓存的历史记录中将你列为定线员 (`@yourlogin`) 的不同路线。规则与 FA 导入的 `@login` 相同；自由文本姓名不计入。需要启用路线数据导入 (`ROUTE_DATA_IMPORT=true`)，以便在本地保存这些数据行。
- **社区攀登次数（估算）：** 你开辟的线路中已缓存的攀登记录数（FA/FFA 标记**或**定线署名），减去同次获取时你自己的日志记录数。第二个板块细分了**运动攀/挂片**路线（运动攀装备风格，或任何记录有挂片的路线）。管理员随后的重复攀登或删除操作不会改变旧的快照。这些是攀登总数的估计值，而非独立攀爬者人数或实时计数器；可见性差异和不完整的管理员日志可能会影响这些数据。
- **社区覆盖率：** 卡片显示在所有符合条件的路线中，有多少条已署名的日志路线配有计数快照。已知的零总数显示为零；不可用的计数将被排除，而不是视为零。部分覆盖的情况会明确标注。如果缓存完全缺失，则显示不可用的消息。
- **年份：** 从你第一次 FA 的年份到最近一次。每项 FA 的日期取自你在该线路上**首次记录的完攀**（见下文）。
- **难度范围：** 你最简单和最难的 FA，使用该路线的难度（而非单个绳距）。路线和抱石线路分开列出，因为 Ewbank 和 V 难度无法比较。难度将按照你的路线和抱石显示系统进行展示。
- **风格：** 你的 FA 如何在运动攀、传攀、抱石等风格中细分，使用 theCrag 上的路线风格。
- **最新：** 仪表盘卡片上显示的你最近三次 FA（完整列表请通过攀登日志查看）。
- **各线路社区攀登数：** 仪表盘上显示的前三条署名路线（列表下方有更多统计）。
- **各线路社区攀登数：** 最多显示八条署名路线，按社区估计值排名。每行显示 FA、FFA 和/或定线员署名、风格徽章（运动攀/挂片、传攀、抱石，或来自缓存路线信息的其他已知装备风格）、估计值（或不可用），以及该计数的获取时间。计数的时效性与其它路线信息字段分开存储，因此仅刷新 Beta 或质量本身并不会让计数器假装是新的。

卡片只有在至少标记了一个 FA 后才会对访客可见。在此之前，管理员将看到一份简短的操作说明。

必须启用路线数据导入 (`ROUTE_DATA_IMPORT=true`) 才能填充计数快照。社区总数和管理员计数快照在后台导入期间从路线 API 获取（每次运行 100 条路线，适用速率限制和退避策略）。要自动保持总数和其他路线数据的更新，请将 `ROUTE_DATA_REFRESH_DAYS` 设置为 30 到 3650 之间的整数天数（例如：建议设为 `90`，或设为 `180` 代表约半年），并同时设置 `ROUTE_DATA_IMPORT=true`。路线在达到该天数后即符合更新条件，并在日志同步成功后进行更新，与新路线共享 100 条路线的配额。新路线优先处理，然后是最旧的过期数据；大量积压可能需要多次同步。未设置、`0`、小于 30 或超过 3650 将保持“仅获取一次”的行为；“设置”中的“**全部刷新**”仍作为可选的手动重置选项。手动标记和取消标记会受到保护。

在“设置”中，路线历史检查按钮会倒计时，直到允许下一次运行并自动变为可用。运行的最小间隔为一分钟；如果出现阻塞或错误，可能需要等待更长时间。在不使用 JavaScript 的情况下，请重新加载“设置”页面以更新可用状态。

## 判定为 FA 的条件及其日期

首次攀登指的是完攀，因此每项首次攀登的日期均取自你在所标记线路上**首次记录的完攀**。磕线过程中的早期尝试和挂绳休息记录不计入，之后的重复攀登也不计入。如果目前只记录了尝试，该线路仍会显示在卡片上（采用最早一次攀登记录的日期），但只有记录完攀后才会解锁徽章或里程碑。

## 徽章与里程碑

这些奖励根据所有者标记的 FA/FFA（以及每条标记线路上你首次记录的完攀）解锁，与是否显示私人笔记无关。里程碑卡片和徽章目录使用相同的阈值 — 而非每条路线占一行。

- **首次攀登**与**首次自由攀登：** 你对标记为 FA 或 FFA 路线的首次完成。
- **首升综合计数**（5、10 / 开拓者、20、50、100）：标记为 FA 或 FFA 的不同路线数量达到该数值。
- **首次自由攀登计数**（5、10、20、50、100）：仅计算 FFA 标记。
- **风格首升计数**（针对运动攀、传攀和抱石分别为 10、20、50）：该装备风格下标记为 FA 或 FFA 的数量。
- **定线员**、**路线开发者** (5)、**岩壁筑造者** (10)、**岩场建筑师** (25)：来自缓存路线历史记录的定线员署名，日期采用每条路线上署名为你的 `@login` 的最早定线条目（而非根据日志记录的完成情况）。
- **共享岩场** (10)、**人气线路** (50)、**百手齐攀** (100)、**当地经典** (500)：根据匹配的计数快照，估计你所开路线（FA/FFA 或定线）的社区攀登总数。计数是攀登次数，而不是独立攀爬者人数。徽章详情中会注明覆盖范围不完整的情况。
- **新线热议** (10)、**运动攀磁石** (50)、**挂片经典** (100)：同样的估计值，但仅限于运动攀装备风格或挂片路线。

每个阈值的时间取决于越过该阈值的路线的首次完成日期；详情中会列出解锁该奖励的路线名称。

没有有效历史日期的定线员署名仍计入定线员徽章，但其获得日期将被视为未知。同样地，社区攀登徽章的获得日期也为未知 — 总数是缓存的聚合数据，而不是具体的事件日期。
