# 攀登者档案

**攀登者档案**雷达图比较了你在**近 30 天**（内圈数据系列）与**近 90 天**（外圈数据系列）的攀登表现。每个坐标轴的分数均为 0–100，基于你的本地日志 — 而非 theCrag 排行榜得分。

## 坐标轴

| 坐标轴       | 评估维度                              |
| --------- | --------------------------------- |
| **攀登量**   | 相对于时间窗口长度，你记录的攀登数量。               |
| **风格多样性** | 出现的不同攀登风格数量（运动攀、传统攀、抱石……）。        |
| **攀登密度**  | 相对于时间窗口，你有过攀登记录的活跃天数。             |
| **攀登高度**  | 相对于时间窗口所攀登的米数（攀登或线路高度）。           |
| **强度**    | 时间窗口内的平均与巅峰有效难度等级（更难的打卡记录会推高该分值）。 |
| **稳定性**   | 结合完攀率与视攀/闪攀占比，衡量线路完成情况和首次尝试成功的比例。 |

分值上限为 100 分。休整期会让坐标轴向内收缩；而高强度的外攀行程或磕线阶段则会使其向外扩张。请将图表形状视为一种提示，而非定性诊断。

## 解读 30 天与 90 天对比

- **过去 90 天**（青色填充）是你的近期基准。
- **过去 30 天**（蓝色轮廓）展示了最近一个月在各个坐标轴上是高于还是低于该基准。

如果任一多边形为空，说明你在该时间窗口内尚未记录足够的带日期攀登数据。
