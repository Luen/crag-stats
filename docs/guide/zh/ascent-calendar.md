# 攀登日历

**攀登日历**是一张展示你一年中记录攀登日期的热力图。单元格会链接至该日期的 `/logbook?day=`。

## 强度

颜色深浅取决于你当天记录的攀登数量（空白 → 少量 → 较多），使用相同的绿色热力渐变。尝试次数也会计入强度；悬浮提示仍会将完登次数单独区分开来。

## 难度

每天的颜色取决于当天**最高难度的成功完登**，使用与其他位置难度标签相同的“新手 → 精英”区间调色板。仅有尝试（未完登）的日期使用较暗的“尝试”填充色。当同一天同时包含抱石和线路难度时，日历会选用编号较大的难度分档——不同分级体系的分档并不完全可比。

你的“强度 / 难度”偏好设置会保存在浏览器中（`cs_heatmap_mode`）。

## 天气

当选择性开启的[天气缓存](/docs/weather)包含你的任何攀登日期时，会出现第三种**天气**模式。每个进行了攀登的日期会根据其包含天气缓存的首次户外完登时的天气状况着色：下雪、下雨、酷热（35°C+）、严寒、宜人（15–25°C 且干燥）或温和，使用与徽章相同的规则。没有天气缓存的日期（岩馆、无坐标、尚未获取）保持暗灰色。悬浮提示会列出最高温、最低温和降雨量，日历下方的**查看天气数值**表格以文本形式提供所选年份的相同数据。

无论浏览器处于哪个时区，即使遇到夏令时切换，日历单元格也会保留记录中的日历日期。它们不会将攀登日期转换为本地时间戳。
