# 离线模式

在连接网络时安装 PWA 或打开已安装的应用，会自动下载离线副本。在普通浏览器标签页中，打开页脚的 **离线副本** 并选择 **下载或刷新副本**。此浏览器会保存一份只读的仪表盘摘要（包括攀爬记录、完攀次数和攀爬高度）以及最近多达 5,000 条攀爬日志。搜索功能可在这些已下载的记录中运行。页面会说明已下载的记录行数；它不会下载每个仪表盘图表或其他应用页面。

下载后，已安装的 PWA 可以在没有互联网或无法访问你的家庭服务器的情况下重新打开。在服务器不可用时打开页面将带你进入离线查看器。你也可以将 `/offline` 加入书签。当前打开的应用导航可能会显示连接错误；请使用其页脚的 **离线副本** 链接。同步、设置、编辑、theCrag 链接和其他页面需要连接网络。不提供离线攀爬日志编辑器。

查看器使用 UTC 标注保存时间，并始终显示这是一个快照。已安装的应用在启动、重新连接和返回前台时会进行检查，且在可见时每分钟检查一次。副本在保存至少一小时后才会刷新；自动尝试失败后会等待至少五分钟再重试。新安装的应用在连接网络后会立即下载。如果网络可用但无法连接你的家庭服务器，将保留上一个可用的副本。离线查看器在打开或重新连接时也会刷新现有副本。

在浏览器支持并允许的情况下，已安装的应用即使在关闭时也会请求每日后台更新。浏览器根据连接情况、电量和应用使用情况决定何时运行这些更新；且不保证一定会更新。不支持定期后台同步的浏览器会在已安装的应用打开时进行刷新。在进入离线状态前，请保持应用连接足够长的时间，以完成首次下载。

## 隐私与保留

安装该应用会启用本地下载，因此请仅在你愿意保留公开可见的线路名称、日期、难度等级和搭档的本地副本的设备上进行安装或下载。私人笔记、原始供应商数据、凭据和“设置”响应内容绝不会包含在内。普通应用页面及其服务器数据响应绝不会被离线 worker 保存。

全应用密码保护（`APP_PASSWORD` 加上 `AUTH_SCOPE=all`）会禁用数据下载，包括已登录的所有者。空的离线查看器仍然可以访问。这可以避免保留可能绕过登录的已认证攀爬日志页面。使用外部访问代理时，浏览器下载的内容仍为本地副本：在共享设备前，清除它是你的责任。

选择 **清除离线副本** 以删除已下载的数据并暂停自动下载，包括在重新启动或更新应用之后。**下载或刷新副本** 将恢复下载。退出登录，以及在设置中清空数据等操作，也会清除此浏览器的离线副本并暂停自动下载，同时处理正在进行的下载和其他已打开的查看器标签页。其他浏览器在下次连接到服务器时，会获知清除操作、更改的笔记可见性/难度等级偏好或全应用保护设置。服务器无法立即撤回已断开连接设备上的副本。

下载内容将在七天后过期（并在打开或检查时被移除）。下载限制为 10 MB。应用更新会移除旧版本 worker 构建保存的副本；除非暂停了自动下载，否则已安装的应用会在连接网络时下载替代副本。你的浏览器可能会更早清除存储，尤其是在无痕浏览或存储压力较大的情况下。清除浏览器的网站数据会移除所有离线资源以及暂停偏好设置。

## 安装与支持

Service worker 需要 HTTPS 或 localhost。普通的 HTTP 局域网地址无法使用离线模式；请为手机/家庭网络安装配置 HTTPS。必须获得浏览器对存储的许可。包括 iOS 主屏幕应用在内的一些浏览器，仅在首次打开已安装的应用时才显示安装；请在连接网络时打开它以准备其副本。离线模式在支持的浏览器标签页以及已安装的 PWA 中均可运行。
