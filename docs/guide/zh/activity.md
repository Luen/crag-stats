# 活动

仪表板上的 **月度统计** 和 **年度统计** 卡片让攀登总量一目了然。**活动**（`/activity`）是当你需要查看比图表更详细信息时的详情页：包含完整的按月拆分表格（攀登记录、完攀数、高度、类型组合）以及逐年的同比拆分。

## 统计规则

- **攀登记录** — 当天、当月或当年记录的每次攀登（包括尝试）。
- **完攀** — 被归类为完攀的记录（参见[攀登记录类型](/docs/tick-types)）。
- **高度** — 根据攀登记录或线路中已有的高度数据计算，单位为 m。
- **类型** — 按攀登方式分为运动攀、传统攀和抱石；其余类型在表格中均归入**其他**。

点击月份链接可打开该日历月的攀登日志。年份链接（位于每年卡片/表格上）可打开 `/logbook?year=`。

## 为何独立设页

如果仅单独重复展示这两个图表，会造成侧边栏臃肿。“活动”页面凭借承载 **每月拆分表格** 并让同比增量易于查阅而获得独立路由 — 这正是解决仅展示简单卡片问题时设定的标准。

## 连续攀登

“连续攀登”卡片在显示历史**最长**连续天数的同时，展示当前的连续天、周和月（共四个指标方块）。最长连续记录的开始和结束日期显示在指标方块下方。当存在时长相同的最长记录时，显示最早发生的日期范围。单次攀登日仅显示一个日期；无历史记录则不显示记录日期。

页脚还显示你最近的攀登日、当前连续攀登中断后距该日经过的完整天数，以及生涯**活跃天数**（不重复的攀登日期数）。天数来源于有效的攀登日期记录；无论尝试还是完攀、室内还是室外均同等计入，同一天的多次攀登仅计算一次。参见 [徽章](/docs/badges) 了解 7 天、10 天和 30 天里程碑。

当前的连续攀登天数截止到今天；若你今天尚未攀登，则截止到昨天。日历日比较统一使用 UTC 时间，因此服务器时区和夏令时变更不会改变已记录的日期。未来日期的记录不会延长当前的连续天数。

当前连续周和连续月遵循相同的宽限规则：计算截止到当前周期的连续周期数；若当前周期尚未攀登，则计算截止到紧邻的上一个周期的连续周期数。在经过一整周或一整月没有攀登后，该计数器归零。周从星期一开始，日历边界使用 UTC 时间，包括跨 ISO 第 53 周和跨新年。未来日期的记录不计入这些计数器。

## 近期活动

仪表板优先列出最新的**攀登日**。在每一天内，最新**记录**的攀登排在最前，采用提供商的日志创建时间戳。显示的日期仍为攀登日期：今天补录较早的攀登，不会使其排序高于较晚攀登日的攀登。当你按顺序输入攀登记录时，记录顺序仅代替攀登顺序，而非记录的实际攀登时刻。

缺少或日志时间无效的记录排在同一天有时间的记录之后。当日志时间相同或不可用时，按已保存的攀登记录 ID 从新到旧排列，以保持顺序稳定。编辑/同步时间戳不会被用作日志创建时间。

近期活动也会显示与攀登日志一致的攀登方式徽章：线路所属类别、适用时显示与线路不同的已记录保护方式，以及先锋独攀或顶绳独攀等明确记录的独攀类型。缺少搭档记录并不意味着独攀。
