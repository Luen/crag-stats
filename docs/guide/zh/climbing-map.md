# 攀登地图

“地图与岩区”页面展示了你在世界各地攀登过的足迹。发光标记会随着记录的攀登次数增加而变大，包括重复攀登在内；次数越多，光芒也越强。攀登次数并不等同于独立线路数；数值表同时列出了这两项指标。

在当前缩放级别下，相邻地点会在投影网格中聚类显示。每个地点仅属于一个聚类。放大地图可将其展开，或选择某个标记以查看单个地点及准确次数。“适应地点”功能会使用最短经线弧度来框选筛选出的位置，包括跨越国际日期变更线的情况。世界轮廓采用等角矩形投影，因此高纬度地区的形状会有所变形。

按日期范围、风格和室内/室外/全部进行筛选。日期范围包含两个端点日；当设置了日期范围时，不完整的日期将被跳过。风格匹配攀登风格或线路风格，与日志中一致。每个地点均链接至确切的已筛选日志查询，该查询在排序、分页和表单提交后依然有效。聚类会列出其包含的各个地点，而不是构建具有误导性的组合名称过滤器。

稳定的数据提供商区域 ID 可保持重命名区域归为一组，并将同名岩场区分开。在没有区域 ID 的情况下，分组将使用数据提供商、规范化的国家/名称和四舍五入的坐标；未命名场地则退而使用线路标识。上游名为“To be deleted”的暂存区域会被排除在地图地点和岩场列表之外；其攀登记录仍保留在日志中并计为未定位。缺失或无效的坐标会被单独统计，绝不会移动到 0,0。位于 0,0 的真实位置依然有效。缓存的岩场坐标可能是近似值。天气回退数据的解析与地图坐标分开处理，不会移动这些标记；参见[天气](/docs/weather)。

轮廓采用打包的 Natural Earth 公有领域数据。查看页面时，不会向第三方服务发送地图瓦片、攀登数据、笔记或位置请求。适用现有的全应用身份验证。完整的数值表以及原生标记/导航按钮支持键盘和屏幕阅读器访问。地图没有动画效果。

在地图下方，展开某个岩场即可浏览其分级岩区并打开其日志链接。此列表包含所有已记录的攀登，不受地图筛选条件的影响。缓存的祖先链提供嵌套岩区；否则线路将使用其直接父级岩区。可用时将显示缓存的到访天气。
