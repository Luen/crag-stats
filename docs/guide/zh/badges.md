# 徽章

大多数徽章用于庆祝攀岩里程碑：首次攀登日或首次完攀、累计攀登记录数、难度等级等。这些徽章依据你日志中相关攀登记录的日期计算。因此，导入更早的攀登记录可能会将某个攀登里程碑的时间提前。

**迈出第一步** 旨在庆祝你将日志导入 Crag Stats。它的日期是包含至少一次攀登记录的首次成功导入或同步的时间，其计数随该次导入一并保存。后续的同步以及导入更早的攀登记录不会改变此日期。它不与任何单次攀登记录关联。导入时间戳使用网站显示的时区。

如果较旧的数据库中没有已保存的导入日期，则下一次成功且非空的导入将提供该日期。现有的已保存日期将被保留。

清除本地数据会与日志一起重置此里程碑；下一次成功且非空的导入将重新开始建立新的里程碑。

## 排序

已获得的徽章按触发它们的攀登记录排列，最近获得的排在最前。仪表盘卡片仅显示最新的八个徽章。同一天获得的徽章保持其在图库中的原始顺序。 First Moves 和社区攀登估算徽章不与单次攀登绑定，因此它们会排在所有带有攀登日期的徽章之后。

## 计入统计的 Tick 类型

设置 → 显示与可见性中的 **计入统计的记录类型** 设置决定了每个徽章跟踪你记录的哪些攀登。有关设置本身的详细信息，请参阅 [Tick types](/docs/tick-types)。

- 设置为 **仅目标线路与目标** 的 Tick 类型不会计入主要攀登统计和仪表盘总数，但仍可用于赚取徽章：**坚持终有回报**、连续天数连胜、**多绳距之日**、**岩旅一周**、高度里程碑以及其他活动徽章都会继续统计它们。因此，即使你的完成总数保持精简，高度里程碑仍会因尝试过程而持续累积。
- 设置为 **隐藏** 的 Tick 类型不会赚取任何徽章：这些攀登记录将被排除在徽章及所有其他数据分析之外。

这一区分是经过精心设计的。主要统计总数会筛选攀登记录，而徽章反映你的实际活动——一次磕线尝试仍是在岩壁上度过的一天，也会计入相应的活动徽章。如果你期望获得的徽章未出现，请检查其 Tick 类型是被隐藏了，还是仅仅未计入总数。

## 攀登距离

高度徽章统计你记录的攀登总高度：1、5、10、20、50、100 和 150 km。每个徽章的日期取决于使你的累计总高度突破该标记的那次攀登。**单日 250m** 则计算在单个自然日内攀登的总高度。

徽章阈值以公制单位定义，绝不会因显示单位设置而更改。仅显示用词会转换：选择英制单位后，**累计攀登 1 km** 会以英里显示，**单日 250m** 会以英尺显示。无论使用哪种单位制，同样的攀登记录获得的徽章完全相同。请参阅 [Display settings](/docs/display-settings)。

## 天气

**热浪来袭**、**冰封定格**、**雨天照攀**、**雪中攀岩**、**顶风而上**、**晴空万里**、**潮湿粘腻**、**暴雨完攀** 和 **四季攀登** 需要可选的户外天气缓存 (`WEATHER_IMPORT`)。请参阅 [Weather](/docs/weather)。在获取这些日期的数据之前，相关徽章将保持锁定状态。**暴雨完攀** 要求在大雨天成功完成攀登；仅有尝试不算在内。

## 即将达成

在完整的 **[Badges](/badges)** 页面上，**即将解锁** 会列出最多三个最接近完成的未解锁徽章。只有**可计数**的门槛才适用（攀登记录总数、高度、各难度分档的完攀数、FA/FFA 次数、开线数等）。节日、天气日或 First Moves 等一次性徽章将被排除在外。进度首先按目标完成百分比排序（在获得前上限低于 100%），若百分比相同，则优先排列目标较小的徽章。仪表盘的徽章卡片仍仅显示最近获得的徽章。

## 攀登搭档、多绳段与旅行

这四个徽章使用你日志中已有的字段，并以完成它们的攀登日期命名：

| 徽章         | 规则                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------- |
| **热闹保护站**  | 单次攀登记录列出了 3 位或更多不同的搭档（匹配姓名时忽略大小写）。                                                            |
| **多绳距之日**  | 你在一个日历日内完攀了 3 个或更多绳距：绳距范围和列表会展开，并按线路和日期去重。整条线路日志和单绳段日志不会重复计算。当存在缓存的 API 绳段 Tick 时，仅计算成功完成的绳段。 |
| **岩旅一周**   | 你在任何连续 7 天内于 4 个不同的户外岩场记录了攀登。室内岩馆和未知岩场不计入在内。                                                  |
| **坚持终有回报** | 你在至少 4 个不同日期记录过某条线路（包括尝试）后，首次将其完攀。重复攀登你已经完成过的线路不计入在内。                                         |

这些属于一次性徽章，因此不会出现在 **即将解锁** 中。

## 重攀与新线路

这些徽章与 [Repeats vs new routes](/docs/repeats) 卡片遵循相同的规则。线路通过其 theCrag 线路 ID 进行匹配，尝试次数计入统计，每个徽章按完成它的攀登记录确定日期。

| 徽章        | 规则                                                  |
| --------- | --------------------------------------------------- |
| **探索者**   | 在 50 条不同线路上记录的攀登。                                   |
| **岩壁漫游者** | 在 100 条不同线路上记录的攀登。                                  |
| **路线收藏家** | 在 250 条不同线路上记录的攀登。                                  |
| **路书探索者** | 在 500 条不同线路上记录的攀登。                                  |
| **忠实老友**  | 在 10 个不同的日子攀登过同一条线路。同一天内的多次攀登仅计算一次。                 |
| **主场岩场**  | 在同一个岩场的线路上累计完成 25 次重复攀登（线路首次记录日期之后的任何一天）。首次到访不计入在内。 |

这六个徽章均为可计数类型，因此可以出现在 **即将解锁** 中。

## 夏日向阳岩壁

在当地气象夏季记录一次朝向赤道线路的户外攀登：南半球十二月至二月期间朝向为 N/NE/NW，或北半球六月至八月期间朝向为 S/SE/SW。这一保守版本涵盖绝对纬度在 25° 至 60°（不含）之间的区域。与天气日徽章一样，尝试也算作已记录的攀登。该徽章在最早符合条件的日期解锁一次，且没有 Almost there 计数器。

优先使用线路自身的 sun/aspect 日照与朝向标签。当线路自身没有朝向/暴露度标签时，可以继承其**直接父级**（例如其分区 sector、岩壁 cliff 或大石 boulder）的标签。缓存标签的来源 ID 必须与该直接父级完全匹配。来自更高级别父级、未知来源和广阔地理区域的标签绝不会填补进来。即使父级的标签不同，线路自身的朝向/暴露度标签也会优先使用；未知或冲突的线路朝向不会触发对父级标签的后备继承。

在所选级别上，**All day sun** 无需朝向指示即可符合条件。 **Always shady** 会阻止获得该徽章。否则，朝向必须如上所述面向赤道；仅限早晨/中午/下午日照的标签单独不能满足条件。不需要同时具备日照和朝向标签。

室内攀登、无效日期、热带/高纬度地区、精度未知的旧数据点以及附近城镇近似数据均不符合条件。缓存数据升级可在无需再次同步或发起外部请求的情况下恢复线路/父级/更高级别父级的出处信息。

这将记录数据提供商描述的朝向/暴露度以及季节性启发式计算。它不确定你的具体攀登时间、实际阳光、仰角遮阴或岩石温度，且不需要 Open-Meteo 缓存。单独的高温徽章描述缓存的高气温数据。精简的真实 API 标签测试固定数据 fixtures 及其出处已在代码库中进行文档说明。

## 绿点攀登

**绿点** 是一个一次性徽章，用于奖励自带传统攀器械先锋完成一条挂有膨胀钉的运动攀线路。当你首次满足以下任一条件时解锁：

- 记录 theCrag 中被归类为完攀的**绿点**、**绿点视攀**或**绿点闪攀**，或者
- 完攀一条类型为**运动攀**的线路，并将此次攀登记录为**传统攀**，使用无坠落和挂绳休息的先锋记录（视攀、闪攀、红点、粉点、自下而上红点或先锋）。

通用的 Tick/Send/Clean 记录、尝试、顶绳攀登和跟攀不适用于第二种途径，因为它们无法证明你使用了器械进行先锋攀登。与上述徽章一样，它不会出现在 **即将解锁** 中。关于 Green point 记录的定义方式，请参阅 theCrag 的 [tick types](https://www.thecrag.com/en/article/ticktypes)。

## 首次绳索独攀

**首次先锋独攀**会在你首次成功完攀且明确记录为先锋独攀时解锁。**首次顶绳独攀**会在你首次以有绳独攀 / 顶绳独攀方式成功完攀时单独解锁。每个徽章都会链接到最早符合条件的攀登记录，并使用攀登记录 ID 区分同日完成顺序，且两者均不会出现在 Almost there 中。

分类规则与 Solo climbing 卡片一致。[提供商 API](https://www.thecrag.com/en/article/api) 记录了 `leadsolo` 和 `ropedsolo`；系统可识别显示标签及其大小写/空格/分隔符变体，而不会更改原始的 Tick 文本。仅当存储的提供商数据载荷确认了相同的明确 Solo 方法时，缓存数据升级才会修复旧的完成标志。线路攀登项目与攀登风格保持独立。

尝试、磕线挂绳、撤退、无保护独攀、深水独攀、器械独攀、普通顶绳攀登以及完成状态不明的记录均不符合条件。明确记录为 Boulder 或 Second 的攀登也与任何绳索独攀方式相矛盾，无法解锁这些徽章。仅凭缺少搭档信息并不能证明是独攀。这些里程碑适用于室内和户外攀登，不需要坐标或天气导入。

## 连续天数连胜

**连续 7 天**、**连续 10 天**和**连续 30 天**徽章用于庆祝连续多个日历日每天至少记录一次攀登。尝试也计入统计，室内和户外攀登均计入，与连续攀登卡片的规则一致。单日内的多次
攀登仅算作一天；缺失或无效的日期不能构成有效天数。决定连胜的是攀登日期，
而非记录时间，且不会在不同时区之间改变记录的
日期。

每个徽章的日期定位在达到其阈值的最早日期。适当休整
不会抹去你历史记录中的里程碑。这些是一次性奖励
且不会出现在 Almost there 中。

## 与你一同攀登的搭档

与符合条件的攀登记录关联的已获得徽章会显示其记录的攀登同伴。 “Partners on this ascent” 仅指所链接的那次攀登，包括跨越多个绳段、天数或线路获得的徽章。它并不是为整项成就作出贡献的所有人的列表。缺少姓名并不意味着是独攀。
