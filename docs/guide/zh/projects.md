# 目标线路

Crag Stats 会在攀登日志中记录了**至少两个不同攀登日**的未完攀尝试后，将该户外线路列为**正在攻克的目标线路**。仅在一日内进行的多次尝试不会创建开启的项目。一年内没有任何活动，开启的项目将会消失。

**已完成的项目**是指经过至少两天的尝试后完攀的线路，或者在**完攀当天至少有两次不成功的尝试**（包括完攀那次在内共三次或更多尝试）。尝试可以是独立的记录项，也可以记录在完攀记录的尝试次数中。独立的记录项和完攀次数不会相加，以避免重复计算相同的尝试。首次尝试即完攀，以及一次失败后在同一天完攀的线路，不归为攻克项目。仅计算第一次完攀前的尝试；之后的重复攀爬不会将早期的完攀转变为项目。缺失或无效的日期无法确定攀登场次。已完成的项目会出现在过去六个日历月的“**近期完攀**”栏目中。

当尝试和首次完攀都包含时间戳时，该次完攀之后的尝试将不计入分类。由于完攀当天的仅日期条目无法确定先后顺序，它们将被视为完攀前的尝试。同一日期内若有多次完攀且无可用时间戳，将按存储的攀登顺序排列，因此后来的重复攀爬不会取代首次记录的完攀。卡片和仪表盘上的场次总数使用与分类器相同的有效日历天数。

“**近期完攀**”涵盖 UTC 时间过去六个日历月，包括仅日期记录的边界日。月末时，边界日期会限定为对应月份的最后一个有效日（十月 31 日回溯至四月 30 日）。未来的日期将被排除。带有时间戳的完攀记录在边界处保留参考时钟。当仪表盘使用近期完攀填充空闲的项目槽位时，使用相同的时间窗口。

## 选择你自己的项目

所有者可在攀登日志的 FA/FFA 控件旁，以及目标线路卡片和详情页，看到简洁的目标线路按钮：

- **标记目标线路**可将已记录的户外线路选为目标，即使只攀登过一天或已一年没有活动。
- “**不是项目**” / “**取消标记**”会将其从项目列表、仪表盘和活动项目计数中移除，直到所有者再次标记或恢复自动检测。
- **使用自动识别**会移除手动选择，并恢复上述规则。

每个标签按钮都会直接保存。记录本中的标签按钮会让你保持在当前过滤页面；项目卡片/详情页的标签按钮则会返回项目列表。“项目 / 不是项目”标签通过文字显示手动选择，而不依赖颜色区分。

选择属于本地元数据，在同步、缓存重建，甚至线路上游被删除后重新出现时都能保留。这些选择不会更改 theCrag 的攀登日志或其公开的 Project 标志。只有真实记录的完攀才会使选中的项目变为已完攀状态。六个月窗口之外的手选完攀记录将出现在“**更早的已选完攀**”下，而非“近期完攀”。设置 → 清空会清除这些选择。访客可以查看生成的项目，但无法更改选择。室内线路和未记录的线路无法手动添加。

## 项目详情、进展与预估

在项目页面或仪表盘点击项目名称即可打开其详情页。它显示线路信息、已缓存的公开指南摘要、按日期的进度，以及之前的尝试/完攀记录（包括攀爬的路段/Pitch 标签）。底部的链接会打开该线路的所有记录项，包括早期的重复攀爬。私人攀爬笔记保留在记录本中，并遵循现有的“仅所有者可见”设置。

“**近似就绪度**”进度条遵循目标就绪度方法：它衡量的是支持性证据，而非等级的百分比或完攀的概率。只有在该线路上的完攀记录才能填满进度条。另一条相同等级的线路无法填满它。早期的场次仅使用截至当天可用的证据，因此后来的完攀不会改写之前的就绪度。

对于每个参考日，模型使用前 365 天（包括当天）相同类型和等级体系下的户外完攀记录，并采用实际攀爬等级。支持性金字塔计数使用不同的线路；重复攀爬不会再次填充金字塔。目标线路不计入支持性证据。

- 最近在目标等级或以上的最佳完攀：60 分；低一个等级：35 分；低两个等级：10 分；否则为零。
- 低于目标一个等级的两条不同线路最多贡献 20 分，低于目标两个等级的四条线路最多贡献 25 分。
- 目标线路上的失败尝试最多贡献 15 分，大致需要 15、35 或 75 次尝试。当与最近最佳成绩的差距最多为一个等级时，周期为“**短期目标**”；差距为两个等级时为“**中期目标**”；否则为“**长期目标**”（在没有已知近期完攀记录时也为长期）。
- 基础模型上限为 94%，之后在该线路上每增加一个有效攀登日，准备度增加一分（第一天建立基准），最高为 99%，直到记录该目标线路的完攀。未知等级没有预估。支持 V 等级中的零级和负等级，绝不与线路难度混合。

练习可以提高进度条，但这并不证明某个特定动作已被攻克。难度和已记录的投入无法揭示动作解法、条件、伤病或信心，因此这是一种可解释的经验估算，并非经过科学验证的模型。

“**预计剩余工作量**”会对比你在相同类型和体系、且等级差距在一个数字等级内的历史已完成户外项目。首次尝试即完攀不纳入比较样本；未达到整条线路难度的部分绳距完攀，不能替代整条线路的完攀。对于每一项指标，必须至少有三个已完成项目的场次/尝试次数多于你目前记录的次数。显示的范围是这些总数减去你已记录工作量后的中间部分（第 25 至第 75 百分位数，使用闭合观察排名）；剩余尝试次数包括最后成功的完攀。当你超过历史记录或对比样本太少时，系统会隐藏预估值，而不是虚构一个截止期限。对比样本包含所有记录年份，而就绪度则使用最近的完攀记录。

这些预估仅描述已完成的项目：未完攀的项目和未记录的尝试不计入其中，且个人能力会随时间变化。它们是粗略的个人对比，并非对剩余工作量的保证。场次总数按记录中有效的日历日期计算。缺失、无效或未来的日期会列在历史记录中，但不计入进展/预估。完攀条目的尝试次数包含成功的那次，并可能与独立的失败条目重叠；摘要使用较大的失败总数，而不是将两者相加。之后的重复攀爬保持可见，且不会改变首次完攀完成项目的时间。

## 新线路？

当项目在 theCrag 上**没有等级**（或等级标注为“Project”/“Proj”）时，卡片会显示“**新线路？**”徽章——这通常意味着是你正在打眼挂片或仍在尝试的新线路。该徽章也适用于**跨度较大的暂定难度范围**，如 `21-23` 或 `V1-3`，这通常表示难度仍在确定中。 `V1/2` 这类相邻半级仍视为普通的已发布难度，不显示该徽章。有可解析的中点时，难度标签仍会显示该中点；改变的只是徽章。明确的 theCrag **Project** 标志（来自线路信息导入）会改为显示单独的目标线路徽章。

## 项目卡片上的路书文本

当**线路数据导入**已缓存某条线路的公开指南数据时，项目卡片可以显示：

- 简短的**描述**摘要
- 当指南列出准入问题（例如关闭或仅允许有限使用的岩场）时的**准入**警告

这些文本来自 theCrag 的公开线路页面（即 Description 和 Access issues 等 `beta` 字段）。这**不是**你的私人记录本笔记。

### 隐私

- **私人攀爬笔记** (`ascents.comment`) 保持独立。它们仅在你从“设置”中选择加入时才会出现在记录本中，绝不会出现在项目卡片或仪表盘统计数据中。
- **路书 Beta** 是公开的社区内容。 Crag Stats 在与 FA 历史相同的选择性线路导入过程中将简短摘要存储在 `routes.beta_json` 中，绝不会与笔记混淆。

### 许可与署名

theCrag 路书内容可能按[知识共享署名—相同方式共享](https://creativecommons.org/licenses/by-sa/4.0/)等许可条款授权。线路页面通常会向贡献者（例如当地俱乐部）致谢。 Crag Stats 仅显示**简短摘要**，并提供返回 **theCrag 线路页面**的链接，同时标注来源 (CC BY-SA)。有关完整描述、伦理规范、进山路线和当前准入状态，请使用卡片上的链接。

线路导入功能**默认关闭** (`ROUTE_DATA_IMPORT`)。如需路书摘要和自动 FA 提示，请在服务器上设置 `ROUTE_DATA_IMPORT=true` 并重启；隐私和请求频率限制请参见[首次攀登](/docs/first-ascents)。
