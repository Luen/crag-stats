# Karma

theCrag 会针对向攀登索引做出的贡献授予 **Karma** —— 记录攀登和编辑路书数据。请参阅 [theCrag 上的 Karma](https://www.thecrag.com/article/cragkarma)。

## Crag Stats 可显示的内容

支持者 **攀登日志** API 账户对象**不**包含你的个人 Karma 总分或攀登/编辑明细。区域 `/karma` 端点是岩场的贡献者排行榜，不能替代你的账户分数。

在 theCrag 公开个人 Karma（或获得授权访问）之前，仪表板卡片仅是**攀登部分的近似值**：

| 来源                    | 分数                                      |
| --------------------- | --------------------------------------- |
| 记录攀登                  | **1** 每条线路（节点）一次，符合 theCrag 每种贡献类型一次的规则 |
| 路书编辑（描述、线路示意图、历史记录、…） | **不可用** —— 无法从记录本缓存中重建                  |

当你同步的账户包含 `routesTicked` 且该数值至少与本地线路缓存一样大时，卡片将使用该数值作为攀登总数（这与 theCrag 上的“你记录过的线路”相匹配）。否则，它会统计本地 SQLite 缓存中不同线路的数量。

**本地记录的线路**磁贴始终显示与你缓存的攀登记录相关的不同线路数量，即使攀登估算使用的是数值更大的账户计数器。重复记录仅计分一次；没有攀登记录的线路元数据不计入。

## 它不是什么

- 并非 theCrag 个人资料中分数的完全同步克隆。
- 真实的 Karma 会在**审核队列**中停留约一周，然后才会存入你的账户。
- 删除或编辑攀登记录、私密账户以及历史导入可能导致本地计数与 theCrag 不同步。
- 我们**不会**基于 FA 标记或定线员署名来生成编辑分数 —— 虽然这些活动可能在 theCrag 上赚取 Karma，但计分规则是每个节点每种贡献类型仅限一次，且我们没有你的编辑历史记录。

## 何时会改进

如果 theCrag 将 Karma（或攀登/编辑总数）添加到记录本账户负载或我们可以安全同步的已文档化攀登者端点中，Crag Stats 就可以用真实数字替换估算值，并填充编辑磁贴。
