# 攀登者类型

仪表盘会为你标注一个**攀登者类型**，例如 _运动攀登者_ 或 _攀岩者_。它位于仪表盘顶部以及“攀登者类型”卡片中。

## 判定规则

1. **在所有记录类型均计入统计时，优先使用 theCrag 的设置。** 如果你的 theCrag 账户设置了攀登者类型（通过 API 同步），Crag Stats 会直接沿用该类型。一旦你在设置中将任何记录类型设为 _仅项目与目标_ 或 _隐藏_，该标签将改为根据你计入的攀登次数重新计算，这样尝试项目的攀登记录就不会让你归入错误的攀登类型。
2. **否则，根据你的攀登日志计算。** 每次计入统计的攀登都会归入对应的攀登类别（保护方式）：运动攀、传统攀、抱石、顶绳、高山攀登、器械攀登、深水独攀等。默认情况下，尝试次数也会计入，但你可以在设置中配置[计入的记录类型](/docs/tick-types)，以防止攻克项目时的尝试（例如反复尝试抱石线路）影响你的攀登者类型判定。
3. **40% 规则。** 如果单一攀登类型占你所有计入攀登记录的**至少 40%**，_且_ 该类型为**运动攀、传统攀或抱石**，你就会被标注为“运动攀登者”、“传统攀登者”或“抱石攀登者”。
4. **其他所有情况**均为**综合攀岩者**。这涵盖了没有任何攀登类型达到 40%，或者占比最高的是顶绳等情况。

卡片中的彩色进度条展示了每种攀登类型的占比，所用颜色与其他位置保持一致：运动攀为蓝色、传统攀为橙色、抱石为红色。

## 为什么是 40%？

大多数攀登者会尝试多种攀登类型。远低于 50% 的阈值仍能体现明确的偏好（例如 47% 运动攀、24% 抱石和 24% 传统攀），同时不会强行将全能型攀登者归入单一类别。各项攀登时间分布较为均匀的攀登者将保持为“攀岩者”。

## 如何更改

- 在你的 theCrag 个人资料中设置攀登者类型并进行同步，
- 如果攻克项目的尝试影响了你的攀登类型占比，可以在设置中调整计入的记录类型；或者
- 记录更多你认同的攀登风格。标签会在下次加载页面时更新。
