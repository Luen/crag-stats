# 难度与难度区间

Crag Stats 显示难度的方式与 [theCrag](https://www.thecrag.com/en/article/grades) 一致。每种难度系统都会被转换为一个统一的内部标尺，该标尺被划分为五个以颜色区分的**区间**。

## 难度如何进行比较

- **每种攀登类型对应一个内部标尺。** 线路（运动攀、传统攀、顶绳攀、阿尔卑斯等…）使用 **Ewbank 难度制** 难度系统进行评分（即澳大利亚数字系统）。抱石使用 **V级** 系统进行评分。它们永远不会混在同一个列表中：V5 的抱石线路和 21 级的攀爬线路分属于不同的金字塔图。
- **难度等级决定分级标尺，而非攀登方式。** 深水独攀和高岩抱石即使不归类为抱石，也常使用 V 等级。这些攀登仍使用 V 等级：统计最高难度完攀和难度指数时与抱石一同计算，并有独立的金字塔图（例如 **DWS · V**），不会混入 Ewbank 金字塔。
- **你的显示系统**可在**设置 → 显示与可见性**中为每种攀登类型分别进行选择。**线路难度**（Ewbank、法国系统或 YDS；默认为 Ewbank）涵盖了运动攀、传统攀、顶绳攀以及其他绳攀项目。**抱石难度**（V-scale (Hueco) 或枫丹白露系统；默认为 V-scale）涵盖了抱石和使用 V 难度的高球项目。两者是独立的，因此你可以同时显示法国系统线路和 Font 抱石。分享链接可以通过 `?system=`（线路或抱石系统）和 `?boulderSystem=` 临时覆盖这些设置。
- **指定难度 vs 你的难度。** theCrag 会同时存储线路的共识难度和你给出的难度。 Crag Stats 优先采用攀登记录中符合选定系统的难度，如果没有，则回退到线路的原始难度。
- \*\*查看单次攀爬。\*\*目标线、项目历史和日志会首先显示你选择的难度。当 theCrag 上的原始线路难度不同时，它会显示在括号中，例如 `6b (20)`。对于多段攀登的部分段落攀爬，第一个难度仍描述你所攀爬的绳段；括号内显示线路的原始难度。未评分的难度将保留其原始文本，而不会尝试猜测转换。
- \*\*多段攀登：\*\*攀爬记录的实际难度是&#x4F60;_&#x81EA;&#x5DF1;_&#x6240;攀爬的最难绳段，而非线路中最难的绳段。对于文本解析器无法识别的分级体系，如 UIAA，完整攀登或绳距难度匹配时会使用该次攀登的通用分数。其他绳段在可用时将使用其难度区间的中间值。
- **模棱两可的抱石数字：** 提供方的难度系统上下文将决定一个单纯的数字代表的是 V-scale 还是 Ewbank。 API 记录中的难度等级绝不会仅因国家/地区的不同而改变。修复操作会保留原始的 API 证据。 CSV 导出文件中没有难度系统列，因此带有单纯数字（如 `9`, `1`）的澳大利亚抱石记录将根据国家 / 岩场路径 / australia URL 存根获得 AU 提示；明确标注为 `V5` / `VB` 的则保留为 V-scale。与 API 导入相同，推断出的 AU 攀爬难度不会覆盖明确的 V-scale 线路难度。
- **难度范围**如 `V1/2` 按中点计算（V1.5）。
- **theCrag 的通用评分。** theCrag 在一个统一的难度标尺上对所有难度系统中的每个等级进行评分。同步的攀爬记录带有该评分，因此 Crag Stats 可以对 theCrag 支持的任何系统（UIAA、萨克森、北欧、波兰、巴西系统等）进行难度排序，即使是那些它无法解析为文本的系统。这些系统中的单纯数字（如 UIAA 的 `7`）绝不会被误认为是 Ewbank 难度。
- **中间难度。** 法国系统、YDS 和枫丹白露系统的转换也使用 theCrag 的评分，因此没有对应完整 Ewbank 或 V 难度的等级（如法国系统的 `5c+`、`6a` 和 `7a+`，枫丹白露系统的 `6A+` 和 `7C+`）仍然严格排在相邻难度之间（`7a` < `7a+` < `7b`）。法国系统、YDS 和枫丹白露金字塔图按该显示系统中最接近的难度进行分组，若恰好处于中间，则归入较难的一级。每一行都链接到日志中对应的难度范围。 Ewbank 和 V-scale 金字塔图保留完整难度的行。难度分档也取自 theCrag 的分数，因此法国难度 `6a` 仍归为进阶，`7a+` 仍归为熟练。
- **CSV 上传**没有评分列，因此它们的难度是从文本中读取的。法国系统、YDS、Ewbank、V 和枫丹白露难度按上述方式转换；其他系统的难度可能显示为未转换。

## 仪表板难度记录

仪表板首先显示**最难完攀**和**最难视攀 / 闪攀**。它们以你选择的系统显示你有史以来成功完成的最高难度和首次尝试即成功的最高难度。尝试和未评分的攀爬不计入内。线路和抱石有各自独立的结果；使用 V 难度的 DWS 和高球计入抱石结果中。多段攀爬的部分记录使用你所攀爬的最难绳段难度。每个结果都会标明其完成方式并链接到相应的攀爬记录。视攀和闪攀的最高难度相同时，显示视攀记录。缺失的记录会显示破折号和说明。
