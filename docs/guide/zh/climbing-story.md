# 攀登故事

**攀岩故事**卡片将你的日志记录转化为仪表板上一段简短的第一人称简介。默认情况下，它位于顶部附近的**最近活动**旁边；自定义仪表板可以移动其中任何一个卡片。它是根据本地统计数据生成的解读性文案——并非第二个可编辑的日志，且绝不会包含私人的攀登记录笔记。

## 始终显示的内容

当你有了第一个记录日时：

1. 你的攀登时长以及活跃天数。
2. 攀登、完攀、Onsight、线路和区域 (以及账户同步提供的室外/室内信息)。
3. 当已知高度时，将攀登高度比喻为珠穆朗玛峰 / 酋长岩。
4. 每个活跃日的攀登次数。
5. 攀登者类型以及你倾向于 Onsight/Flash 还是红点/磕线 (沿用与其他地方相同的 55% 多数原则)。

## 可选行（仅当特征显著时）

按优先级顺序最多选择**三句**额外说明。跳过接近的并列项和微小样本，以使卡片保持在大约 5–7 段。

| 特征信号       | 示例                                                                                                | 门槛（约）                                                                                                                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 你开辟的线路     | “我喜欢开辟运动攀线路——那些其他人不断攀爬的超级经典线路。我完成了 18 次首升。我开辟的最受欢迎的线路是 Sample Classic，它是一条拥有超过 120 次攀登记录的超级经典线路！” | 风格优先级 **Sport → Trad → Boulder**；需要明确的开辟计数。如果有 ≥2 条线路具有社区**其他攀登者的攀登次数**数据：其中 ≥55% 的线路该次数 ≤5 → 冷门/探险线路；≥55% 的线路该次数 ≥50 → 超级经典线路（取代总计“攀登超过 N 次”的描述）。否则，当该攀登类别中其他攀登者的攀登次数合计 ≥ 10 时，保留合计数值。如果已知，始终列出你开辟的线路中最受欢迎的一条；当该线路中其他攀登者的攀登次数 ≥100 时，超级经典线路的描述还会包含格式化后的社区攀登次数估算值。计数是攀登次数的估算值，而非不同的人数。 |

开辟线路使用来自缓存线路历史的 FA/FFA 标记和定线者署名。运动攀的措辞是“开辟运动攀线路”；传统攀是“开辟传统攀线路”。只有当运动攀和传统攀数据较弱时，抱石才会胜出，因为抱石线路更容易开辟。冷门与超级经典线路的描述，以及最受欢迎的开线描述，均使用与首次攀登卡片相同的社区**其他攀登者的攀登次数**快照。

最受欢迎的开辟线路名称会链接到其在 theCrag 的线路页面。计数是“首升”功能中使用的已缓存的**其他攀登者攀登估算值**（不包括所有者配对的攀登快照），而非实时计数或不同人数的计数。它遵循你的数字显示区域设置。缺失或不安全的缓存链接在可用时会使用规范的 theCrag 线路 ID；否则名称将保持为纯文本。查看故事不会向提供商发起请求。

## 它不包含的内容

- 不是 CPR、Karma 或排行榜上的炫耀。
- 非 LLM 生成——仅使用模板，因此具有相同统计数据的两次安装会得到相同的措辞。
- 笔记在日志中仅对所有者可见；它们绝不会出现在这里。
