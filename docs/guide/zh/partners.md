# 攀爬搭档

**攀爬搭档**页面（以及仪表盘卡片）会根据你在日志本的 `with` / partners 字段中标记的人员进行排名。点击姓名即可打开日志本并筛选出该特定搭档的记录。

## 指标 (`/partners`)

使用右上角的切换按钮：

- **攀登次数**（默认）— 每一条标记了该搭档的攀登记录
- **攀爬日** — 至少有一次共同攀登的独立日历天数（与[每周攀爬场次](/docs/sessions-per-week)中的“场次 = 天”概念相同；无效占位符如 `2018-00-00` 会被跳过，与“周几”页面一致）
- **区域** — 与该搭档一起攀爬过的不同岩场，可用时会使用缓存的供应方区域 ID。重命名将保持单一身份，而名称相同但 ID 不同的岩场将保持独立。没有 ID 时，按岩场名称匹配且不区分大小写；空名称和“Unknown”名称会被跳过。仅当某个岩场名称只对应一个 ID 时，只有名称的记录才会归入该已知 ID

你的选择将存储在浏览器中（`cs_partners_metric`）。

## 备注

- 用户名会被规范化（去除开头的 `@`）；大小写不同但指向同一人的名称将共享一个柱条。
- 拥有多条记录的多段攀登日对**攀登次数**的影响比对**攀爬日**的影响更大。
- 如果你只在某一个岩场与某人攀爬，那么在**区域**指标下，其排名会低于记录较少但经常一起去外地攀爬的搭档。

仪表盘预览和详情页使用相同的攀登记录，包括那些无法获取线路详情的历史记录。缺失线路详情不会删除搭档攀登次数或有效的攀爬天数；但在没有已知场地的情况下，它们不会计入区域数。其他基于线路的仪表盘分析仍需要线路记录。

仪表盘卡片与此页面共享你选定的指标，并显示该指标排名前七位的搭档。点击其“攀爬搭档”标题即可查看完整列表。

徽章、最高难度完攀、亮眼攀登、近期活动，以及具体线路的难度/首次攀登里程碑，也会显示已记录的搭档。归属取决于所选的攀登记录，而非该线路的每一次重复。线路级别的开发/社区卡片和聚合里程碑不会推断同伴。姓名去重时不区分大小写；缺失的姓名会被略过，绝不视为独攀的证据。
