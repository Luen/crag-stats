# CPR (攀登者表现评分)

**CPR 评分** 是 theCrag 对你攀登能力的评分。与 theCrag 一样，Crag Stats 分别显示**运动攀**、**传统攀**和**抱石**的 CPR 时间线，因为这三种攀登类别的评分方式差异很大。

## theCrag 如何计算 CPR

theCrag 通过对大约一百万条记录进行的统计分析建立了 CPR。主要思路：

- **每个等级比其低一级难约 5 倍**（Ewbank 等级上的幂因子 _P_ = 5）。你攀登过的每条不同线路，都会将 _P_ 的该线路难度等级次方计入总分。总分通过以 5 为底的对数转换回等级。因此，在某个等级完成五次攀登的分值大约等同于在更高一级完成一次攀登。
- **记录偏移。** 你的攀登方式很重要。在计分之前，记录会根据等级偏移进行调整。例如，运动攀登者的红点难度通常比视攀高约 **2.1 个等级**；传统攀中，粉点比红点约容易 **0.8 个等级**。偏移量是针对运动攀、传统攀和抱石分别计算的。
- **巩固等级。** 在一个新等级获得一次完攀记录可能只是因为线路容易或是运气好。你的_等级_只有在获得大约 **三次** 该等级的记录后才会提升，但每一次攀登仍会增加你的评分。
- **衰减。** 如果你停止攀登，CPR 每年会下降约 **0.7 Ewbank 等级**（大约四分之三个等级）。
- 线路的**重复**仅计算一次（取最佳记录），且使用的是线路分配的等级，而非你的个人意见。

theCrag 为运动攀、传统攀和抱石各保留了一个衰减和未衰减的评分。

## Crag Stats 如何获取评分

- **来自 theCrag 的 API（首选）。** 当你使用支持者 API 密钥进行同步时，每次爬升都可以携带 theCrag 自身的 CPR 值。如果某攀登类别中带有 CPR 值的记录足够多（至少 3 次，且至少占该类别记录的 20%），时间线会采用 **theCrag 的衰减 CPR**，标记为 _theCrag CPR_。
- **近似模型（备用）。** 否则，Crag Stats 会计算自己的 CPR，标记为 _Approx._。它采用相同的逻辑：_P_ = 5、每条线路的最佳记录、记录偏移以及每年 0.7 个等级的衰减。记录偏移量为估算值，例如运动攀：视攀 +2.1、闪攀 +1.4、红点 0、粉点 −0.5、尝试 −3。**这不是 theCrag 专有实现的副本**，因此可能会有细微差别。

## 阅读时间轴

- 每个**列**代表一个季度。
- **蜡烛图**显示了你在该季度使用各种记录类型所攀登的等级范围。与 theCrag 一样，最纯粹的记录位于顶部：视攀绿色、闪攀黄色、红点红色、粉点粉色、完攀/干净完攀蓝色、尝试灰色。
- **黑线**代表你随时间变化的 CPR。圆圈标记你的**峰值**，空心点标记你**当前**的评分。
- **彩色背景**按真实难度边界显示难度分档（入门 → 精英）。
- 下方的**柱状图**显示了你在该季度记录的爬升次数。点击其中一个可在日志本中查看这些爬升记录。
- 时间轴上带有 **⋯** 的**虚线分隔符**表示超过一个季度的间隔。
- **显示空白季度**会在你第一次和最后一次记录的季度之间，为每个季度分配独立的列。没有爬升记录的季度将保持空白并**使黑线断开**，因此长时间的停练不再被显示为稳步进展。当额外的列需要更多空间时，图表会水平滚动。保持未勾选状态以使用紧凑视图，此时仅有爬升记录的季度才会显示列。

theCrag 注意到，线段上方的**灰色顶端**（更高等级的失败尝试）通常出现在等级跨越提升之前。
