# リピート vs 新規ルート

**リピート vs 新規ルート**カードは、あなたの登攀のうち、過去に記録したことのあるルートと、自分にとって新しいルートの割合を示します。デフォルトでは**ルートの人気度**の後に配置され（ハーフサイズ）、ダッシュボードのカスタマイズで移動させることができます。

## カウントの対象

有効なカレンダーの日付とプロバイダーのルートIDがある限り、完登もトライも、記録されたすべての登攀がカウントされます。

- **初回訪問**とは、そのルートを初めて記録した日のすべての登攀を指します。同じ初日のトライと完登は、どちらも初回として扱われます。
- **リピート**とは、後日、同じルートで行われた登攀を指します。

ルートは名前ではなく theCrag のルートIDで照合されるため、「Arete」という名前の異なる二つのルートは別々に扱われます。「日」は、タイムゾーンの補正なしで、ログブックに記入された登攀日を基準にします。

## フィルター

- **全期間** または **過去12ヶ月**。短期間の範囲は、今日までの365日間です。ある登攀がリピートかどうかは常に全履歴に基づいて判断されるため、三年前に初めて登ったルートは、今年はリピートとしてカウントされます。
- **すべて**、**スポーツ**、**トラッド**、**ボルダリング**。これらはログブックのスタイルフィルター（登攀スタイル**または**ルートスタイル）と一致します。トップロープやその他のスタイルは、**すべて**の中だけに表示されます。

選択内容は、このブラウザに保存されます（`cs_repeats_range`, `cs_repeats_style`）。

## ラベル

現在のビューに少なくとも20件の登攀記録がある場合、カードに短く説明的なラベルが追加されます：

| ラベル           | ルール                   |
| ------------- | --------------------- |
| **エクスプローラー**  | 登攀の少なくとも75%が初回である場合   |
| **リピートクライマー** | 登攀の少なくとも50%がリピートである場合 |
| **両方のミックス**   | その中間の状態               |

しきい値は正確な割合を使用しますが、カードに表示されるパーセンテージは四捨五入されています。どちらのスタイルが優れているということはありません。プロジェクト、トレーニングラップ、お気に入りのサーキットなどはすべてリピートとして表示されます。

## 最多リピート

現在のビューで最も頻繁に再訪したルートを最大五つまで、登った日数の多さ、次に登攀回数、最後に直近の登攀日の順でランク付けして表示します。それぞれがログブックのエントリにリンクしています。

## 表示条件

ルートIDを持つ日付付きの登攀記録が少なくとも20件になるまで、カードは非表示のままです。
