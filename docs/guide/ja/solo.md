# ソロクライミング

**ソロクライミング**カードは、タイプ別のソロ登攀に加えて、パートナーをタグ付けせずに記録したすべての登攀をカウントします。

## どの種類がどのソロとしてカウントされるか

これはtheCragでのティック記録方法（[theCragのティックタイプ](https://www.thecrag.com/en/article/ticktypes)）に従います：

| カード上の項目     | theCragでの記録内容                                                              |
| ----------- | -------------------------------------------------------------------------- |
| トップロープソロ    | **Roped Solo**のティック：上からセットされたロープでセルフビレイを行い、一人でトップロープで登った場合。                |
| リードソロ       | **Lead solo**のティック：リードソロ用デバイスを使用し、末端を固定したロープでリード登攀をした場合。                   |
| フリーソロ       | **フリーソロ**のクライミングスタイルで、任意のティック（オンサイト、フラッシュ、レッドポイントなど）を記録した場合：ロープを一切使用しない登攀。 |
| ディープウォーターソロ | **ディープウォーターソロ**のクライミングスタイル。                                                |
| エイドソロ       | **Aid solo**のティック。                                                         |

各タイプについて、登攀数と完登数、それらの期間、および**最高難易度の完登**を確認できます。これは実際に登ったグレードを使用するため、一部のみを登ったマルチピッチは、最高難易度のピッチでカウントされます。ルートはEwbankグレード、ボルダーはVグレードを使用し、これらが相互に比較されることはありません。両方のグレードがある場合は、最高難易度のルートが表示されます。

## パートナーのタグなし

最後の行は、theCragの**With**フィールドに誰も入力されていない登攀数と、そのうちの完登数をカウントします。これはソロクライミングとは同じではありません。これには、誰かと一緒に登ったもののタグを付けなかった日や、インドアでのセッションも含まれます。これは、パートナーを記録せずに登る頻度を測るためのおおよその指標であり、ロープソロやフリーソロも含みます。

## 初のロープソロ・バッジ

**Lead solo**および**Roped Solo / Top rope solo**の完登に成功すると、それぞれ個別の初達成バッジがアンロックされます。カードとバッジは、ドキュメント化された`leadsolo`や`ropedsolo`識別子、および一般的な大文字小文字/スペース/区切り文字のバリエーションを含む、明示的なソロティックの正規化を共有しています。元のプロバイダーのティックテキストは保持されます。カードでは完登していない明示的な登攀もカウントされますが、バッジには完登の成功と有効なカレンダー日付が必要です。[バッジ](/docs/badges)を参照してください。

ソロタイプのカードをクリックすると、アテンプトを含むログブック内のすべての一致する登攀が表示されます。ソロタイプのフィルターは、ソート、ページ移動、または他のフィルターの変更を行っても選択状態が維持されます。最高難易度の完登リンクからは、引き続きtheCrag上のその個別の登攀ページを開くことができます。
