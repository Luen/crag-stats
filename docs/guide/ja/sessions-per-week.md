# 週ごとのセッション

**週ごとのセッション**カードは、選択した年に記録された週ごとのクライミング**セッション**数をカウントします。

## セッションとは何ですか？

セッションとは、ログブックに少なくとも一つの完登がある**カレンダー上の日**のことで、プロジェクトカードの「セッション」と同じ考え方です。同じ日に二つのチックがあっても、一つのセッションとしてカウントされます。記録のない日は空のバーとして表示されます。

## 平均

**週平均セッション数**は、その年の合計セッション数を見表示されている週数（カレンダー年と重なる約52〜53のISO週）で割ったものです。登らない冬の時期は平均を下げ、集中的な遠征期間は平均を押し上げます。

週は月曜日から始まります（登攀日のUTC日付に基づきます）。バーをタップすると、その週のログブックが開きます。

セッション分析では、厳格なUTCカレンダー日の検証が行われます。プレースホルダー（`2018-00-00`）、存在しない日付（`2024-02-31`）、および日付のない記録はセッションとしてカウントされません。うるう日は、うるう年にのみ受け入れられます。ブラウザやサーバーのタイムゾーンに関係なく、同じ日付に繰り返されたチックやタイムスタンプは、一回としてカウントされます。このポリシーは、パートナー、曜日、ダッシュボードのアクティブな日、および天候のデータと共通です。
