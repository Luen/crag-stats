# 岩質

theCragでは、多くのルートの地質情報を構造化された**岩質**タグ（例：花崗岩や砂岩）として保存しています。 Crag Statsは同期されたログブックやルートキャッシュからそのタグを読み取ります。ページをスクレイピングしたり、岩場の名前から岩質を推測したりすることはありません。

## 岩質カード

ダッシュボードの**岩質**カードは、岩質タグが設定されているルートの登攀数を集計し、それぞれの名称の割合を表示します。最も多い岩質については、短い地質学的な説明が表示されることがあります。各名称は `?rock=` でフィルタリングされたログブックにリンクしています。

岩質タグのないルートはチャートから除外されるため、パーセンテージはタグ付けされたクライミングのみを対象としています。

## 岩質とパフォーマンスのカード

岩質タグ付きのルートで完登またはトライが少なくとも一回含まれるクライミング日が**20日以上**になると、**岩質とパフォーマンス**カードで、それらの登攀結果を岩質別に比較します。それまでは、これまでにタグ付けされた日数が表示されます。タグ付けされた完登やトライが存在しない間、カードは非表示のままになります。「設定 → ダッシュボード」から移動や非表示の設定が可能です。

**集計対象。** 岩質タグのあるルートでの完登とトライ（他の箇所と同じ記録分類）。タグのないクライミングは、網羅性（「あとN件の… 「...岩質タグがありません」）。

**指標**（[天気とパフォーマンス](/docs/weather)と同じ考え方）：

- **完登率：** その岩質における完登とトライの合計に対する完登の割合。
- **限界付近：** その日の前365日以内における、**同じスタイルおよびグレード体系**での最高完登グレードから2グレード以内（Vスケールでは1グレード以内）のグレード付き完登の割合。 Vスケールとルートグレードが混ざることはありません。
- **オンサイト/フラッシュ：** その岩質における完登数に対するオンサイトおよびフラッシュの割合。

**結果を正確に読み取る。**

- 岩質ごとの割合が表示されるには、少なくとも**3日**にわたって計**10回**以上の登攀（その指標の分母となる数）が必要です。
- **高い** / **低い**には、天気パフォーマンスと同じクラスターロバスト検定が使用されます。各「岩質と日」のグループを一つの単位とするため、一つの大きなセッションだけでパターンが作られることはありません。
- 岩場の選択、遠征、プロジェクトなどは、岩質による影響を判断する際に交絡因子となります。差異は因果関係ではなく、相関関係として扱ってください。
- 多くの異なる岩質名がある場合、頻度の低いものは**その他**（ログブックへのリンクなし）にまとめられます。各名称の帯は、岩質カードと同じ大文字小文字を区別しない一致条件で `/logbook?rock=…` にリンクします。

カードを表示してもプロバイダーへのリクエストは発生せず、プライベートなメモが使用されることもありません。

限界付近の基準には、基準となるルートに岩質タグがない場合でも、同じスタイル・同じグレード体系の完登が含まれます。可能な場合は最も難しい登攀ピッチのグレードを使用し、365日前を含み、比較対象となる当日の完登はすべて除外されます。岩質と天気のパフォーマンスはこの基準計算を共有していますが、天気の場合はさらに基準となる完登を外岩での登攀に限定しています。
