# オフラインモード

オンライン中にPWAをインストールするか、インストール済みのアプリを開くと、オフラインコピーが自動的にダウンロードされます。通常のブラウザタブでは、フッターの **Offline copy** を開き、 **Download or refresh copy** を選択してください。このブラウザには、読み取り専用のダッシュボード概要（アセント数、完登数、登攀高度）と、最大5,000件の最新ログブックデータが保存されます。検索は、ダウンロードされたこれらのデータの範囲内で機能します。ページにはダウンロードされたデータの件数が表示されます。ダッシュボードのすべてのチャートやその他のアプリページがダウンロードされるわけではありません。

ダウンロード後は、インターネット接続やホームサーバーへのアクセスがなくても、インストール済みのPWAを再度開くことができます。サーバーが利用できないときにページを開くと、オフラインビューアが表示されます。 `/offline` をブックマークすることも可能です。アプリを開いている最中にナビゲーションに接続エラーが表示される場合があります。その場合は、フッターにある **Offline copy** リンクを使用してください。同期、設定、編集、theCragへのリンク、およびその他のページには接続が必要です。オフライン用のログブックエディタはありません。

ビューアには保存時刻がUTCで表示され、常にスナップショットであることが示されます。インストール済みのアプリは、起動時、再接続時、フォアグラウンドに戻った時、および表示中は一分ごとにチェックを行います。ダウンロードから少なくとも一時間が経過すると更新されます。自動試行に失敗した場合は、再試行まで少なくとも五分間待機します。新規インストール時は、接続されるとすぐにダウンロードが開始されます。ネットワークは利用可能だがホームサーバーに接続できない場合、最後に使用可能だったコピーが保持されます。オフラインビューアは、起動時や再接続時にも既存のコピーを更新します。

ブラウザでサポートおよび許可されている場合、インストール済みのアプリは閉じている間でも、毎日バックグラウンド更新を要求します。実行タイミングは接続状況、バッテリー、アプリの使用状況に基づいてブラウザが決定するため、実行が保証されるものではありません。定期的なバックグラウンド同期に対応していないブラウザでは、インストール済みのアプリが開いている間に更新が行われます。オフラインになる前に、最初のダウンロードが完了するまでアプリを接続状態にしておいてください。

## プライバシーとデータの保持

アプリをインストールするとローカルへのダウンロードが有効になります。そのため、公開されているルート名、日付、グレード、パートナー名のローカルコピーを保存しても差し支えのないデバイスにのみ、インストールまたはダウンロードを行ってください。プライベートなメモ、プロバイダーの生データ、認証情報、および設定のレスポンスが含まれることはありません。通常のアプリページとそのサーバーデータレスポンスがオフラインワーカーによって保存されることはありません。

アプリ全体のパスワード保護（`APP_PASSWORD` と `AUTH_SCOPE=all`）が有効な場合、サインインしているオーナーを含め、データのダウンロードは無効になります。データのない空のオフラインビューアには、引き続きアクセス可能です。これにより、ログインをバイパスして閲覧できてしまう可能性のある、認証済みのログブックページが保持されるのを防ぎます。外部アクセスプロキシを使用している場合でも、ブラウザのダウンロードデータはローカルコピーとして残ります。デバイスを共有する前に、データを消去するのはユーザーの責任となります。

**Clear offline copy** を選択すると、ダウンロードされたデータが削除され、アプリの再起動や更新後も含めて自動ダウンロードが一時停止されます。 **Download or refresh copy** を選択すると、自動ダウンロードが再開されます。ログアウトや設定のワイプなどの変更操作を行うと、このブラウザのダウンロードデータも消去され、進行中のダウンロードや他の開いているビューアタブを含め、自動ダウンロードが一時停止されます。他のブラウザについては、次にサーバーに接続した際に、ワイプ、メモの表示設定やグレード設定の変更、またはアプリ全体の保護設定が適用されます。オフライン状態のデバイスにあるコピーを、サーバーから即座に無効化することはできません。

ダウンロードは七日後に期限切れとなります（また、開かれた際やチェックされた際に削除されます）。ダウンロードは 10 MB に制限されています。アプリが更新されると、古いワーカービルドによって保存されたコピーは削除されます。自動ダウンロードが一時停止されていない限り、接続時に新しいコピーがダウンロードされます。ブラウザの判断により、特にプライベートブラウジング中やストレージ容量が不足している場合、データが早期に削除されることがあります。ブラウザのサイトデータを消去すると、すべてのオフラインアセットが削除され、一時停止の設定もリセットされます。

## インストールとサポート

サービスワーカーには HTTPS または localhost が必要です。通常の HTTP LAN アドレスではオフラインモードを使用できません。スマートフォンやホームネットワークにインストールする場合は、HTTPS を設定してください。ブラウザでストレージの使用が許可されている必要があります。 iOS のホーム画面アプリなど一部のブラウザでは、インストール済みのアプリを最初に開いた時にのみインストール処理が実行されます。オンライン中にアプリを開いてコピーを準備してください。オフラインモードは、対応しているブラウザのタブでも、インストール済みの PWA と同様に機能します。
