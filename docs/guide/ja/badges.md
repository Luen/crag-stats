# バッジ

ほとんどのバッジは、初めてのセッションや完登、登攀数の合計、グレードなどのクライミングのマイルストーンを祝うものです。これらはログブック内の該当する登攀日を使用します。そのため、過去の登攀データをインポートすると、マイルストーンの達成日がより古い日付に前倒しされることがあります。

**First Moves** は、ログブックを Crag Stats にインポートしたことを祝うバッジです。日付は少なくとも一つの登攀記録を含む最初のインポートまたは同期が成功した日となり、その時点のカウントがインポート情報と共に保存されます。その後の同期や、さらに古い登攀データのインポートによってこの日付が移動することはありません。このバッジは個別の登攀記録にはリンクしていません。インポートのタイムスタンプには、サイトの表示タイムゾーンが使用されます。

古いデータベースにインポート日時が保存されていない場合、データを含む次のインポート成功時に設定されます。既存の保存済み日付は維持されます。

ローカルデータを消去すると、ログブックと共にこのマイルストーンもリセットされ、データを含む次のインポート成功時に新たに設定されます。

## 順序

獲得したバッジは、それを獲得した登攀記録順に、最新のものから表示されます。ダッシュボードのカードには最新の八つが表示されます。同じ日に獲得したバッジは、ギャラリーの並び順が維持されます。 First Moves およびコミュニティ登攀数の推定値は特定の登攀記録に紐付いていないため、日付のあるすべての登攀バッジの後に表示されます。

## カウント対象のティックタイプ

「設定 → 表示と視認性」にある**カウント対象のティックタイプ**設定によって、記録された登攀のうちどれが各バッジのカウント対象になるかが決まります。設定自体については [ティックタイプ](/docs/tick-types) をご覧ください。

- **プロジェクト & 目標のみ**に設定されたティックタイプは、メインの登攀数やダッシュボードの合計からは除外されますが、バッジ獲得の対象にはなります。**Persistence Pays**、連続日数ストリーク、**Multipitch Day**、**Travel Week**、高度マイルストーン、その他のアクティビティバッジでは引き続きカウントされます。そのため、完登数の合計が増えない場合でも、プロジェクトへのトライによって高度マイルストーンは加算され続けます。
- **非表示**に設定されたティックタイプは何も獲得できません。それらの登攀記録はバッジだけでなく、すべての分析データから除外されます。

この区別は意図的なものです。メインの合計数字は完登したものをフィルタリングしますが、バッジは行ったアクティビティを表します。プロジェクトへのトライも岩場で過ごした一日であり、それを祝うバッジのカウント対象となります。期待していたバッジが表示されない場合は、そのティックタイプが単に合計から外れているだけでなく、非表示に設定されていないか確認してください。

## 登攀距離

高度バッジは、記録された登攀の総高度をカウントします：1、5、10、20、50、100、150 km。それぞれのバッジは、累計高度がその基準値を超えた登攀の日付が付けられます。一方、**250m Day** は単一のカレンダー日に登った高度を合算します。

バッジの閾値はメートル法で定義されており、表示単位の設定によって変更されることはありません。表記のみが変換されます。ヤード・ポンド法を選択している場合、**1 km climbed** はマイル表記に、**250m Day** はフィート表記に変わります。どちらの単位系を選択していても、同じ登攀記録で全く同じバッジを獲得できます。[表示設定](/docs/display-settings) をご覧ください。

## 天候

**Heat Wave**、**Freeze Frame**、**Rain Check**、**Climbing in the Snow**、**Blown Away**、**Bluebird**、**Sticky**、**Storm Send**、および **Four Seasons** には、オプションの屋外天候キャッシュ（`WEATHER_IMPORT`）が必要です。[天候](/docs/weather) をご覧ください。該当する日のデータが取得されるまで、バッジはロックされたままになります。 **Storm Send** を獲得するには大雨の日に完登を達成する必要があります。トライだけではカウントされません。

## もう少し

すべての **[バッジ](/badges)** ページでは、**もう少し**のセクションに達成に最も近い最大三つのロックされたバッジが表示されます。**カウント可能**な閾値を持つバッジのみが対象となります（登攀数の合計、高度、グレード帯ごとの完登数、FA/FFA数、設定ルート数など）。祝日、天候の日、First Moves などの単発バッジは除外されます。進捗状況は目標に対する達成割合（獲得するまでは100%未満でキャップ）でランク付けされ、割合が同じ場合は目標数値がより小さいものが優先されます。ダッシュボードのバッジカードには、直近で獲得したバッジのみが引き続き表示されます。

## パートナー、マルチピッチ、トラベル

これら四つのバッジは、ログブックに既に存在するフィールドを使用し、達成時の登攀記録の日付が付けられます：

| バッジ           | ルール                                                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **混雑したビレイ**   | 一つの登攀記録に3人以上の異なるパートナーが記載されている（名前は大文字・小文字を区別せずに照合されます）。                                                                                 |
| **マルチピッチ・デイ** | 同じカレンダー日に3ピッチ以上を完登する：ピッチ範囲やリストはルート/日ごとに展開され、重複排除されます。ルート全体の記録と個別ピッチの記録が二重カウントされることはありません。キャッシュされたAPIピッチティックが存在する場合、完登したピッチのみがカウントされます。 |
| **トラベル・ウィーク** | 連続する7日間のうちに、4つの異なる屋外クラッグで登攀を記録する。インドアジムおよび不明なエリアはカウントされません。                                                                            |
| **継続は力なり**    | 4日以上（トライを含む）記録したルートを初めて完登する。既に完登したルートの再登はカウントされません。                                                                                    |

これらは一回限りのバッジであるため、**もう少し**には表示されません。

## リピートと新規ルート

これらのバッジは [リピート vs 新規ルート](/docs/repeats) カードのルールを共有します。ルートは theCrag のルート ID で照合され、トライ回数もカウントされます。各バッジには達成した登攀の日付が付けられます。

| バッジ                 | ルール                                                      |
| ------------------- | -------------------------------------------------------- |
| **エクスプローラー**        | 50の異なるルートで登攀を記録。                                         |
| **ワンダラー**           | 100の異なるルートで登攀を記録。                                        |
| **ルート・コレクター**       | 250の異なるルートで登攀を記録。                                        |
| **ガイドブック・エクスプローラー** | 500の異なるルートで登攀を記録。                                        |
| **オールド・フェイスフル**     | 一つのルートを10日間にわたって登攀。一日に複数回登攀しても一回としてカウントされます。             |
| **ホーム・ターフ**         | 単一のクラッグにあるルートで、25回の再登記録（ルートの最初の記録日以降の別日）。初回訪問はカウントされません。 |

これら六つはすべてカウント可能であるため、**もう少し**に表示される可能性があります。

## サマー・サン・フェイス

地元の気象学上の夏に、赤道に面した屋外ルートで登攀を記録する：南半球では十二月〜二月のN/NE/NW、北半球では六月〜八月のS/SE/SW。この保守的な判定基準では、絶対緯度25°から60°まで (境界値は含まない) を対象としています。天候バッジと同様に、トライも記録された登攀としてカウントされます。このバッジは条件を満たす最も古い日に一度だけ解除され、「もう少し」カウンターはありません。

まずルート自体の日照/方角タグを使用します。ルート自体に日照・方角タグがない場合、**直近の親要素**（セクター、岩壁、ボルダーなど）から継承されたタグが補完されます。キャッシュされたタグのソースIDは、その直近の親と正確に一致する必要があります。より上位の親要素、不明なソース、広域エリアからのタグが補完されることはありません。親要素と異なる記述がある場合でも、ルート自体の日照・方角タグが優先されます。ルートの方角が不明または競合している場合でも、親要素へのフォールバックはトリガーされません。

選択されたレベルにおいて、**All day sun** タグは向きがなくても条件を満たすことができます。 **Always shady** タグがある場合、バッジは獲得できません。それ以外の場合、方角は上述の通り赤道に面している必要があります。午前/正午/午後のみの日照タグだけでは条件を満たしません。日照タグと方角タグの両方が揃っている必要はありません。

インドアクライミング、無効な日付、熱帯/高緯度地域、精度不明のレガシーポイント、近隣都市の近似位置は対象外です。キャッシュデータのアップグレードにより、再同期や外部リクエストを行うことなく、ルート/親要素/上位親要素の由来が復元されます。

これはプロバイダーが記述した日照情報に加えて、季節的ヒューリスティックを記録します。登った時間帯、実際の受光状態、ハングによる日陰、岩の温度などを特定するものではなく、Open-Meteo キャッシュも必要としません。別の Heat バッジは、キャッシュされた最高気温を対象とします。最小化された実際の API タグフィクスチャとその由来はリポジトリにドキュメント化されています。

## グリーンポイント

**Greenpoint** は、ボルトが打たれたスポーツルートをプロテクションを使ってリードした際に獲得できる一回限りのバッジです。以下のいずれかを初めて行った際に解除されます：

- 完登としてカウントされる theCrag の **Green point**、**Green point onsight**、または **Green point flash** のティックを記録する、または
- **Sport** と記載されているルートを **Trad** として記録し、ノーフォールでのリード（オンサイト、フラッシュ、レッドポイント、ピンクポイント、グラウンドアップ・レッドポイント、または Lead）で完登する。

一般的な Tick/Send/Clean の記録、トライ、トップロープ、セカンドは、プロテクションを使ってリードしたことが示されないため、二つ目の方法の対象外となります。上記のバッジと同様に、**もう少し**には表示されません。グリーンポイントのティックの定義については、theCrag の [ティックタイプ](https://www.thecrag.com/en/article/ticktypes) をご覧ください。

## 初めてのロープソロ登攀

**First Lead Rope Solo** は、リードソロとして明確に記録された最初の完登時に解除されます。 **First Top-Rope Solo** は、ロープソロ / トップロープソロとして明確に記録された最初の完登時に別途解除されます。それぞれは、同日の重複を解決するために登攀IDを使用して、条件を満たす最も古い登攀にリンクし、どちらも「もう少し」には表示されません。

分類は「Solo climbing」カードと一致します。[プロバイダー API](https://www.thecrag.com/en/article/api) には `leadsolo` および `ropedsolo` が記載されています。表示ラベルやその大文字・小文字/スペース/区切り文字のバリエーションは、元のティックテキストを変更することなく認識されます。キャッシュデータのアップグレードは、保存されているプロバイダーのペイロードが同じ明確なソロ方式を裏付けている場合にのみ、古い完了フラグを修正します。ルートの種別と登攀スタイルは分離されたままとなります。

トライ、ハングドッグ、撤退、フリーソロ、ディープウォーターソロ、エイドソロ、通常のトップロープ登攀、完登状況が不明な記録は対象外です。ボルダーやセカンドとして明確に記録された登攀も、いずれのロープソロ方式とも矛盾するため、これらのバッジを解除することはできません。パートナーの記載がないことだけでは、ソロクライミングとは判定されません。これらのマイルストーンはインドアおよびアウトドアの登攀に適用され、座標や天候データのインポートは不要です。

## 連続日数ストリーク

**7-Day Streak**、**10-Day Streak**、および **30-Day Streak** は、連続するすべてのカレンダー日に少なくとも一つの登攀を記録したことを祝うものです。トライもカウントされ、インドアとアウトドアの登攀も両方カウントされます。これは「ストリーク」カードと一致します。一日に複数の登攀を行っても一回としてカウントされます。日付がない、または無効な日付の場合は日数としてカウントされません。ストリークの判定は記録時のタイムスタンプではなく登攀日によって行われ、タイムゾーン間で書かれた日付がシフトすることはありません。

各バッジには、その閾値に達した最も古い日付が設定されます。休養期間を取っても、記録された履歴からマイルストーンが消去されることはありません。これらは一回限りのバッジであり、「もう少し」には表示されません。

## 誰と登ったか

登攀記録によって獲得したバッジには、そこに記録されている同行者が表示されます。「この登攀時のパートナー」はリンクされた登攀記録のみを指し、これには複数のピッチ、日数、またはルートにわたって獲得したバッジも含まれます。達成全体に貢献した全員のリストではありません。名前の記載がないことが、ソロ登攀を意味するわけではありません。
