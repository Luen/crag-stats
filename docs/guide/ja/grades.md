# グレードとグレードバンド

Crag Statsは、[theCrag](https://www.thecrag.com/en/article/grades)と同じ方法でグレードを表示します。すべてのグレード体系は一つの内部スケールに変換され、そのスケールは色分けされた五つの**バンド**に分割されます。

これらの色は、すべてのピラミッド、グレードチップ、CPRチャート、バンド内訳に表示されます。 theCragの表示と一致しているため、グレードはどちらでも同じように表示されます。

## グレードの比較方法

- **クライミングの種類ごとに一つの内部スケール。** ルート (スポーツ、トラッド、トップロープ、アルパイン…)は**Ewbank**スケール（オーストラリアの数値）でスコア化されます。ボルダーは**Vスケール**でスコア化されます。これらが一つのリストに混ざることはありません。V5のボルダー課題とグレード21のルート課題は、別のピラミッドに分かれます。
- **スタイルではなく、グレードがスケールを決定します。** ディープウォーターソロやハイボールは、ボルダーでなくてもVグレードが付けられることがよくあります。これらはVスケールのまま維持されます。最高完登記録やグレードインデックスではボルダーとしてカウントされ、独自のピラミッド（例：**DWS · V**）に分類され、Ewbankのピラミッドに入ることはありません。
- **表示システム**は**設定 → 表示・視認性**でクライミングの種類ごとに選択できます。**ルートグレード**（Ewbank、フレンチ、またはYDS。デフォルトはEwbank）は、スポーツ、トラッド、トップロープ、その他のロープクライミングを対象とします。**ボルダーグレード**（Vスケール（Hueco）またはフォンテーヌブロー。デフォルトはVスケール）は、ボルダーおよびVグレードが付けられたハイボールを対象とします。この二つは独立しているため、フレンチのルートとFontのボルダーを組み合わせて表示することもできます。共有リンクでは、`?system=`（ルートまたはボルダーのシステム）および`?boulderSystem=`を使用して一時的に設定を上書きできます。
- **設定グレードと自分のグレード。** theCragには、ルートの公式コンセンサスグレードと自分が付けたグレードの両方が保存されます。 Crag Statsは、適切なシステムである場合、登攀記録のアセント時のグレードを優先し、そうでない場合はルートのグレードにフォールバックします。
- **個々のクライミングの読み方。** プロジェクト、プロジェクト履歴、ログブックでは、選択したグレードが最初に表示されます。元のtheCragルートグレードと異なる場合は、`6b (20)`のように括弧内に表示されます。マルチピッチの一部のみを登った場合、最初のグレードはあなたが登ったピッチを表し、括弧内はルート本来のグレードを示します。スコア化されていないグレードは、推測で変換するのではなく元のテキストがそのまま保持されます。
- **マルチピッチ：** 完登記録の有効グレードは、ルート全体の最高難易度ピッチではなく、_あなた_が登った最も難しいピッチになります。 UIAAなどテキストパーサーが読み取れないシステムの場合、全ピッチ完登または該当するピッチのグレードには、完登記録のユニバーサルスコアが使用されます。その他のピッチは、利用可能であればその難易度バンドの中央値を使用します。
- **曖昧なボルダー数値：** 数字のみの場合にVスケールを意味するかEwbankを意味するかは、プロバイダーのグレードシステムコンテキストによって決定されます。国情報のみによってAPI行のグレードが変更されることはありません。修復処理では元のAPIエビデンスが保持されます。 CSVエクスポートにはグレードシステムの列がないため、数字のみ（`9`、`1`）のオーストラリアのボルダー行は、国 / ゲレンデパス / australia URLスタブからAUヒントを取得します。明示的な`V5` / `VB`はVスケールのまま維持されます。 APIインポートと同様に、推定されたAUの登攀グレードが明示的なVスケールのルートグレードを上書きすることはありません。
- `V1/2`のような**レンジ**は、中間値 (V1.5) としてカウントされます。
- **theCragのユニバーサルスコア。** theCragは、あらゆるグレード体系のすべてのグレードを一つの難易度スケールでスコア化します。同期された完登記録にはそのスコアが含まれるため、Crag StatsはtheCragがサポートするすべてのシステム（UIAA、ザクセン、ノーディック、ポーランド、ブラジルなど）のグレードを、テキストとして読み込めないものであっても順位付けできます。これらのシステム内の単一の数字（例：UIAAの`7`）がEwbankと誤認されることはありません。
- **中間グレード。** フレンチ、YDS、フォンテーヌブローの変換にもtheCragのスコアが使用されるため、EwbankやVと同等の整数値を持たないグレード（フレンチの`5c+`、`6a`、`7a+`、Fontの`6A+`、`7C+`など）も、隣接するグレード間で厳密に順位付けされます（`7a` < `7a+` < `7b`）。フレンチ、YDS、Fontのピラミッドはその表示システムで最も近いグレードごとにグループ化され、中間値で並んだ場合はより難しいグレードに割り当てられます。各行はログブック内の対応するグレード範囲にリンクしています。 EwbankとVスケールのピラミッドは整数グレードの行を維持します。それらのバンドもtheCragのスコアに基づいて決まるため、フレンチの`6a`は中級のまま、`7a+`は上級のままになります。
- **CSVアップロード**にはスコア列がないため、グレードはテキストから読み取られます。フレンチ、YDS、Ewbank、V、Fontのグレードは上記のように変換されます。その他のシステムのグレードは未変換のまま表示される場合があります。

## ダッシュボードのグレード記録

ダッシュボードは**最高完登グレード**と**最高オンサイト / フラッシュ**から始まります。選択した表示システムにおいて、これまでの最高完登グレードおよび最高一発完登グレードが表示されます。トライやスコアのないクライミングは対象外です。ルートとボルダーの結果は分かれています。Vグレードが付けられたDWSやハイボールはボルダーとしてカウントされます。マルチピッチの一部のみを登った場合は、あなたが登った中で最も難しいピッチが使用されます。各結果にはそのティック名が表示され、該当する完登記録へリンクします。オンサイトとフラッシュの記録が同等の場合、オンサイトが表示されます。記録がない場合は、ダッシュ記号と説明が表示されます。
