# クライミングマップ

「マップとセクター」ページには、あなたが世界中で登った場所が表示されます。光るマーカーは、リピート完登を含む記録された完登数に応じて大きくなり、数が多くなるほど強力に発光します。カウント数はユニークなルート数とは異なります。数値テーブルには両方の指標が一覧表示されます。

近隣の場所は、現在のズームレベルに応じた投影グリッド上にクラスター化されます。各場所はひとつのクラスターに属します。ズームインして分離するか、マーカーを選択して個々の場所や正確な件数を表示します。「場所の全表示」機能は、日付変更線をまたぐ場合を含め、最短の経度弧を使用してフィルターされた位置を画面内に収めます。世界地図の輪郭には正距円筒図法が使用されているため、高緯度では形状が歪んで表示されます。

日付範囲、スタイル、およびインドア／アウトドア／すべてでフィルターできます。日付範囲には開始日と終了日の両方が含まれます。日付範囲が設定されている場合、不完全な日付データはスキップされます。スタイルは、ログブックと同様に、登攀スタイルまたはルートスタイルのいずれかに一致します。各場所は、並べ替え、ページ送り、フォーム送信を行っても保持される、フィルター済みの正確なログブッククエリにリンクしています。クラスターは、誤解を招く結合名フィルターを作成するのではなく、それを構成する場所を一覧表示します。

安定したプロバイダーエリアIDにより、名前が変更されたエリアをまとめて保持し、同名の岩場を分離して管理します。エリアIDがない場合、グループ化にはプロバイダー、正規化された国／名称、および端数処理された座標が使用されます。無名の場所はルート識別情報にフォールバックされます。 「To be deleted」という名前の上流の保留エリアは、マップ上の場所や岩場リストから除外されます。その完登記録はログブックに残り、未マッピングとしてカウントされます。欠損または無効な座標は個別にカウントされ、0,0 の位置に移動されることはありません。 0,0 に実在する正規の位置は引き続き有効です。キャッシュされた岩場の座標はおおよその値である場合があります。天気データのフォールバック処理はマップ座標とは別に解決され、これらのマーカーを移動させることはありません。[天気](/docs/weather) を参照してください。

地図の輪郭は、バンドルされたNatural Earthのパブリックドメインデータです。ページの閲覧中に、マップタイル、完登データ、メモ、位置リクエストがサードパーティサービスに送信されることはありません。アプリ全体の既存の認証設定が適用されます。詳細な数値テーブルとネイティブのマーカー／ナビゲーションボタンにより、キーボードおよびスクリーンリーダーでのアクセスが可能です。マップのアニメーションはありません。

マップの下で岩場を展開すると、そのセクターを閲覧し、ログブックへのリンクを開くことができます。このリストには、マップのフィルターにかかわらず、記録されたすべてのクライミングが含まれます。キャッシュされた階層構造によってネストされたセクターが提供されます。それ以外の場合、ルートは直近の親セクターを使用します。利用可能な場合、キャッシュされた訪問時の天気が表示されます。
