# プロジェクト

Crag Statsでは、ログブックに**少なくとも二日間の異なる登攀日**にわたって未完登のトライが記録されている外岩のルートを、**進行中のプロジェクト**としてリストします。一日だけの複数回のトライでは、進行中のプロジェクトとはみなされません。一年間活動がない進行中のプロジェクトは表示されなくなります。

**完登したプロジェクト**とは、二日以上にわたる打ち込みの末に完登したルート、または**完登当日に少なくとも二回の失敗トライ**があった (完登を含めて計三回以上のトライがあった) ルートを指します。トライは、個別のログ項目として記録することも、完登時のトライ数として記録することもできます。重複カウントを避けるため、個別のログ項目と完登時のトライ数は合算されません。初回での完登や、一回の失敗の後に同日に完登した場合は、プロジェクトとはみなされません。初回の完登までの打ち込みのみがカウントされます。その後の再登によって、以前の完登がプロジェクトに変わることはありません。日付が不明または無効な場合は、セッションとして成立しません。完登したプロジェクトは、過去六か月間**最近の完登**シェルフに表示されます。

トライと初完登の両方にタイムスタンプがある場合、その完登より後のトライは分類から除外されます。完登日に日付のみが記録されている項目は、その日の内での順序が不明なため、完登に至るまでの打ち込みとして扱われます。有効な時刻がなく同日に複数の完登が記録されている場合は、保存された登攀順序が使用されます。そのため、後からの再登が最初に記録された完登に取って代わることはありません。カードやダッシュボードのセッション合計は、分類器と同じ有効なカレンダー日を使用します。

**最近の完登**は、UTCでの過去六か月間を対象とし、日付のみの完登については境界日も含まれます。月末の場合、境界は最後の有効な日に固定されます (十月31日の場合は四月30日まで遡ります)。未来の日付は除外されます。タイムスタンプのある完登は、境界において基準となる時刻を保持します。ダッシュボードで空いているプロジェクト枠を最近の完登で埋める際も、同じ期間が適用されます。

## プロジェクトの自己選択

所有者には、ログブックのFA/FFAコントロールの横や、プロジェクトカードと詳細ページにコンパクトなプロジェクトボタンが表示されます。

- **プロジェクトとしてマーク**を選択すると、わずか一セッションの後や一年間活動がなかった場合でも、記録された外岩ルートをプロジェクトとして選択できます。
- **プロジェクトではない** / **プロジェクトの解除**を選択すると、所有者が再度マークするか自動検出を復元するまで、そのルートはプロジェクト、ダッシュボード、アクティブなプロジェクト数から除外されます。
- **自動設定を使用**を選択すると、手動での選択が解除され、上記のルールが再度適用されます。

各ボタンを押すと直接保存されます。ログブックのボタンでは現在のフィルタページが維持され、プロジェクトカードや詳細ページのボタンではプロジェクト一覧に戻ります。「プロジェクト / プロジェクトではない」タグにより、色に頼らずに手動選択の状態を確認できます。

選択内容はローカルメタデータであり、同期やキャッシュの再構築、さらには元データでルートが一旦削除されて後に復活した場合でも保持されます。これらは theCrag のログブックや公開プロジェクトフラグを変更することはありません。実際にログに記録された完登のみが、選択されたプロジェクトを完登済みにします。六か月の期間外で選択された完登は、「最近の完登」ではなく**以前に選択された完登**の下に表示されます。設定 → データの消去 で選択内容をクリアできます。訪問者は結果としてのプロジェクトを閲覧できますが、選択内容を変更することはできません。インドアのルートやログに記録されていないルートを手動で含めることはできません。

## プロジェクトの詳細、進捗、予測

プロジェクトページやダッシュボードでプロジェクト名をクリックすると、その詳細ページが開きます。ルート情報、キャッシュされている場合は公開ガイドブックの抜粋、日付ごとのセッションの進捗、および以前のトライや完登（登ったピッチのラベルを含む）が表示されます。下部のリンクから、過去の再登を含むそのルートのすべてのログブック項目を確認できます。非公開の登攀メモは、既存の所有者のみ表示設定に従い、ログブック内に留まります。

**推定準備度**バーは目標準備度アプローチに従っています。これは根拠となるデータの蓄積を測定するものであり、グレードの達成率や完登の確率を示すものではありません。そのルートでの完登がログに記録された時のみ、バーが最大になります。同じグレードの別のルートを登っても、バーは完了しません。過去のセッションではその登攀日までに利用可能だったデータのみを使用するため、後日の完登によって過去の準備度が書き換えられることはありません。

各基準日において、モデルは同じ種目およびグレード体系の外岩での過去365日間（当日を含む）の完登記録を使用し、実際に登ったグレードを基準にします。根拠となるピラミッドのカウントには個別のルートが使用されます。再登によってピラミッドが再度埋まることはありません。ターゲットとなるルート自体は、根拠となるデータから除外されます。

- ターゲット以上での最近のベスト完登：60ポイント、一段階下：35、二段階下：10、それ以外はゼロ。
- 一段階下の二つの異なるルートで計20ポイント、二段階下の四つのルートで計25ポイントが加算されます。
- ターゲットへの失敗トライは、15回、35回、または75回の暫定目標に対して、最大15ポイントまで加算されます。最近のベストとの差が最大一段階の場合は**短期**、二段階の場合は**中期**、それ以外 (または最近の完登記録がない場合) は**長期**となります。
- 基本モデルの上限は94%で、その後、そのルートでの有効な登攀日が一日に増えるごとに一ポイント加算され (初日が基準となります)、完登が記録されるまでは最大99%となります。グレードが不明な場合は予測されません。 Vグレードのゼロやマイナスグレードもサポートされており、ルートのグレードと混同されることはありません。

練習を重ねることでこのバーは上がりますが、特定のムーブが解決されたことを証明するものではありません。グレードや記録された努力量からムーブの核心、コンディション、怪我、自信などを読み取ることはできないため、これは説明可能なヒューリスティックであり、科学的に検証されたモデルではありません。

**推定残り作業量**は、同じ種目および体系で、数値グレードが一段階以内の完登済み外岩プロジェクトの履歴と比較します。初回完登はこのグループには含まれません。また、ルートのグレードを下回る部分的なピッチの完登は、ルート全体の完登の代わりにはなりません。各指標において、これまでに記録されたセッション数やトライ数よりも多くの回数を要した完登済みプロジェクトが、少なくとも三つ存在する必要があります。表示される範囲は、それらの合計から記録済みの作業量を引いた値の中間半分（第25〜75パーセンタイル、隣接する観測順位を使用）です。残りのトライ数には最終的な完登も含まれます。過去の履歴を超えた場合や比較対象が少なすぎる場合は、適当な期限を捏造するのではなく、予測の表示を控えます。比較グループには記録されている全期間が含まれますが、準備度は最近の完登記録を使用します。

これらの予測は完登したプロジェクトのみを対象としています。未完登のプロジェクトや記録されていないトライは考慮されず、能力も時間の経過とともに変化します。これらはおおまかな個人的な比較であり、残りの努力量を保証するものではありません。セッションの合計は、記録された有効なカレンダー日をカウントします。不明、無効、または未来の日付は履歴には表示されますが、進捗や予測からは除外されます。完登時のトライ数には成功したトライも含まれ、個別の失敗記録と重複する場合があります。サマリーでは両方を加算するのではなく、より多い方の失敗回数を使用します。後日の再登は、どの完登が最初にプロジェクトを完了させたかを変えることなく、履歴に表示され続けます。

## 新ルート？

theCragでプロジェクトに**グレードがない**場合（または文字通り「Project」や「Proj」とグレード付けされている場合）、カードには**新ルート？**バッジが表示されます。これは通常、ボルトを打っている最中の新しいラインや、現在開拓中のルートを指します。 `21-23`や`V1-3`のような**幅のある暫定的なグレード範囲**が設定されている場合も同じバッジが表示されます。これは多くの場合、グレードがまだ確定していないことを意味します。 `V1/2`のような隣接するハーフグレードは、通常の公開グレードとして扱われ、バッジは表示されません。グレードチップには、中間値が存在する場合は解析されたその値が表示されます。バッジのみが変化します。 theCragの明確な**Project**フラグ（ルート情報インポートによるもの）がある場合は、代わりに別のプロジェクトバッジが表示されます。

## プロジェクトカードのガイドブックテキスト

**ルートデータのインポート**によってルートの公開ガイドブックデータがキャッシュされている場合、プロジェクトカードに以下を表示できます：

- 短い**説明**の抜粋
- ガイドブックにアクセスの問題（例：閉鎖された岩場、限定的に許容されている岩場）が記載されている場合の**アクセス**警告

これらのテキストは theCrag の公開ルートページ（Description や Access issues などの `beta` フィールド）から引用されます。これは、あなた個人の非公開ログブックメモでは**ありません**。

### プライバシー

- **非公開の登攀メモ** (`ascents.comment`) は別々に扱われます。これらは、設定でオプトインした場合にのみログブックに表示され、プロジェクトカードやダッシュボードの統計には表示されません。
- **ガイドブックのベータ情報**は、公開されたコミュニティコンテンツです。 Crag Stats は、FA履歴と同じオプトイン方式のルートインポート時に、短い抜粋を `routes.beta_json` に保存します。メモと混ざることはありません。

### ライセンスと帰属

theCrag のガイドブックコンテンツは、[クリエイティブ・コモンズ 表示-継承 BY-SA](https://creativecommons.org/licenses/by-sa/4.0/) などの条件でライセンスされている場合があります。ルートページには多くの場合、寄稿者（地元の山岳会など）がクレジットされています。 Crag Stats は**短い抜粋**のみを表示し、**theCrag のルートページ**へのリンクを貼り、出典 (CC BY-SA) を表示します。詳細な説明、倫理規範、アプローチ、現在のアクセス状況については、カード上のリンク先を確認してください。

ルートインポートは**デフォルトでオフ**です (`ROUTE_DATA_IMPORT`)。ガイドブックの抜粋や自動的なFAヒントが必要な場合は、サーバーで `ROUTE_DATA_IMPORT=true` を設定して再起動してください。プライバシーや取得制限については、[初登](/docs/first-ascents)を参照してください。
