# パートナー

**パートナー** ページ（およびダッシュボードカード）は、ログブックの `with` / パートナーフィールドでタグ付けされた人々を順位付けします。名前をクリックすると、そのパートナーと完全に一致するログブックが開きます。

## メトリクス (`/partners`)

右上にあるトグルを使用します:

- **アセント**（デフォルト）— そのパートナーの名前が記載された、すべての記録済みアセント
- **セッション** — 少なくとも一つの共有アセントがある固有のカレンダー日（[週あたりのセッション](/docs/sessions-per-week) と同じ「セッション = 日」の考え方。`2018-00-00` のような無効なプレースホルダーは Weekday 同様スキップされます）
- **エリア** — そのパートナーとクライミングを行った個別の岩場。利用可能な場合はキャッシュされたプロバイダーのエリアIDを使用します。名前が変更されても同一の ID が維持され、異なる ID を持つ同名の岩場は別のものとして扱われます。 ID がない場合、名前は大文字と小文字を区別せずに照合されます。空欄や「Unknown」という名前はスキップされます。名前のみの行は、その名前が単一のIDにのみマッピングされている場合に既知のIDと結合されます

選択した内容はブラウザに保存されます (`cs_partners_metric`)。

## 注意事項

- ハンドル名は正規化され（先頭の `@` は削除）、大文字・小文字表記が異なる同一人物は一つのバーを共有します。
- 多数のティックがあるマルチピッチの日は、**セッション** よりも **アセント** を大きく増加させます。
- 一つの岩場でしか一緒に登らない相手は、ティック数が少なくても様々な場所を訪れるパートナーより **エリア** での順位が低くなります。

ダッシュボードのプレビューとフルページでは、ルート記録が利用できないレガシーアセントを含め、同じ記録済みアセントが使用されます。ルートの詳細が欠落していても、パートナーとのアセントや有効なセッション日が消去されることはありませんが、既知の岩場がない場合はエリア数に反映されません。ルートに基づくその他のダッシュボード分析には、引き続きルート記録が必要です。

ダッシュボードカードはこのページと選択したメトリクスを共有し、そのメトリクスの上位七名のパートナーを表示します。全リストを表示するには、パートナーのタイトルをクリックしてください。

バッジ、最高完登記録、注目すべきアセント、最近のアクティビティ、ルートごとのグレードやFAのマイルストーンにも、記録された同行者が表示されます。帰属表記は、そのルートのすべての再登ではなく、選択されたアセントに従います。ルートレベルの開拓/コミュニティカードおよび集計マイルストーンでは、同行者は推測されません。名前は大文字と小文字を無視して重複排除されます。名前の記載がない場合は除外され、ソロクライミングの証明として扱われることはありません。
