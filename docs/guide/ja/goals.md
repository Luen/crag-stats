# 目標

目標を設定すると、theCrag ログブックのターゲットがダッシュボードおよび **目標** ページの進捗バーに変わります。高度と登攀日の目標は直線的に進行します。**グレード**の目標は、概算の**ピラミッド準備度**モデルを使用しているため、ターゲットより一グレード低い状態がほぼ達成済みのように表示されることはありません。

## 目標の種類

| 種類          | 「完了」の定義                    | 進捗バー               |
| ----------- | -------------------------- | ------------------ |
| **今年のグレード** | 目標とした年に、ターゲット以上のスコアで完登すること | ピラミッド準備度（下記参照）     |
| **今年の高度**   | その年に登ったメートル数               | リニア: メートル数 ÷ ターゲット |
| **今月の日数**   | 今月の実際の登攀日数                 | リニア: 日数 ÷ ターゲット    |
| **カスタム**    | 自分で完了としてマークする              | 手動（自動進行なし）         |

ベニューの範囲（屋外 / 屋内 / すべて）によって、どの登攀がカウントされるかがフィルタリングされます。グレード目標のデフォルトは**屋外**に設定されます。

高度目標は常に**メートル単位で保存**されます。作成フォームでは選択した高度単位（メートルまたはフィート）でターゲットを入力します。フィートの場合は保存前に変換され、進捗およびターゲットのラベルもその単位に従います。後から単位を切り替えても、保存されているターゲットは変更されず、目標の表示ラベルのみが更新されます。[表示設定](/docs/display-settings)を参照してください。

グレード目標は**ルート**または**ボルダー**のスケールを保持します。ターゲットと進捗ラベルは設定で指定されたグレード体系に従います。表示体系を変更しても、ターゲットやパーセンテージは変わりません。提案された目標のタイトルも設定に従いますが、カスタムタイトルは入力された通りのまま保持されます。目標の**グレード設定**で、スケールと自動タイトルを使用するかどうかを選択できます。

目標に**グレードスケールが必要**と表示されている場合、所有者が**ルート**または**ボルダー**を選択するまで進捗は表示されません。タイトルと保存されたターゲットは保持されます。タイトルにグレードが含まれていても、それによってスケールが決まるわけではありません。

## グレード準備度

グレード目標では、目標とする年に**ターゲット以上の完登** (ルートは主にEwbank、ボルダーはVスケールの標準スコア) が求められます。バーは `最高完登記録 ÷ ターゲット` では**ありません**。それだと23の完登がまだ必要なのに、22→23が約96%に見えてしまっていたためです。

代わりにこのモデルでは、ターゲット **N** の下でどれだけピラミッドが構築されているか、そしてそのターゲット近くでどれだけトライしたかを評価します：

1. 対象となる最高完登記録がすでに ≥ N の場合は**完了（100%）**。
2. N−1 での完登がある場合は**ベース**（約35%）、N−2 のみにある場合は（約10%）。
3. それらのバケットで完登した個別のルートによる**ピラミッドの補填** — **N−1 で約2本**、**N−2 で約4本**のルートが緩やかな目安（最大で約+20%および+25%）となります。
4. 実質スコアが **≥ N−1** の未完登 (トライ中) の記録による**トライの補填** — 最大約+20%まで。目標期間に応じて調整される緩やかな目安が設けられており、短期プロジェクトは長期プロジェクトよりも一トライあたりの進捗が大きくなります。
5. **ベースモデルの上限は94%です。** 対象となる最初のセッションでベースラインが決定し、≥ N−1 でのトライ記録がある登攀日が増えるごとに準備度ポイントが一ポイント追加され、最大99%まで増加します。 100%に達するのは、条件を満たす完登のみです。同じ日に複数のルートやトライがあっても一セッションとしてカウントされます。未入力、無効、または未来の日付はカウントされません。セッションのクレジットは目標の年とベニューに従います。高度や登攀日の目標割合には影響しません。

完登の実績判定は完了判定と同じ年・ベニューのフィルターを使用します。**実効グレード** (マルチピッチで最も難易度の高いピッチ) およびピラミッドバケットごとの**個別のルート** (同じルートの複数回完登は一回としてカウント) が適用されます。トライ数は条件を満たす未完登記録をすべてカウントします (同一ルートでの複数回のトライも進捗バーを僅かに進めます)。

進捗行には、最高完登記録、N−1 / N−2 のルート数、トライの実績がある場合、および短期/中長期のヒントが表示されます：

| ターゲットまでの差       | ヒント | 必要トライ数の緩やかな目安（≈ トライ帯を埋める） |
| --------------- | --- | ------------------------- |
| 1グレード           | 短期  | 約15トライ                    |
| 2グレード           | 中期  | 約35トライ                    |
| さらに広いギャップ / 未完登 | 長期  | 約75トライ                    |

## 提案される次のグレード

**目標** ページでは、過去**二年間**に屋外での完登記録がある場合、Crag Stats が控えめな提案を表示することがあります。屋外での最高完登記録 (ルートとボルダーは別々に管理) をもとに、今年の**次のグレードステップ** (V5からV6、25から26など) を目指す提案です。**目標を追加**をクリックするまで、提案によって目標が作成されることはありません。その年の屋外ターゲットをすでに追跡している場合、チップには**追跡中**と表示されます。

## 表示される内容

- **ダッシュボード**の「進行中の目標」カード: 同じパーセンテージとラベルを持つ進行中の目標が数件表示されます。
- **目標** ページ: オプションの「次のグレード」提案チップ、進行中/達成済みの全リスト、作成/編集機能、およびグレード目標用の準備度テキストが表示されます。

## 注意事項

- **概算です。** ピラミッドの数値はコーチング上の経験則の目安であり、N を必ず完登できるという予測ではありません。
- **同一体系のスコア。** サポートバケットは [N−1, N) および [N−2, N−1) のスコア範囲となるため、ターゲット未満の細かい完登も達成度の裏付けとして機能します。スコアは目標の標準スコアを使用します。バー内部で異なるグレード体系が自動変換されることはありません。
- **スケール、年、ベニュー。** ルートとVスケールの実績が混ざることはありません。目標年以外の古い記録や、異なるベニューでの記録は、準備度には反映されません。 Vグレードが付けられたDWSやハイボールは、ギアスタイルではなくグレード体系に基づいてボルダー目標としてカウントされます。
- **トライ数は概算です。** 記録されているのは ≥ N−1 のグレードを持つ未完登のみであり、グレードが付いていないプロジェクトでのすべてのトライが反映されるわけではありません。
- **カスタム目標**がログブックから自動的に進行することはありません。

高度と日数の目標はシンプルな直線比率のまま維持されるため、半分の距離や日数であっても半分進行していると表示されます。
