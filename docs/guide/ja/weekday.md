# 曜日

**曜日**カードは、あなたが何曜日にクライミングを行っているかを表示します。これは [Dreeve](https://dreeve.app/) による Strava 用の曜日チャートを参考にしています。分布は、月〜日の凡例が付いた**ドーナツ（円）グラフ**で表示されます。デフォルトでは、**週あたりのセッション数**の左側（半分幅）にあり、**月間** / **年間**統計の下の行に配置されます。ダッシュボードのカスタマイズで、どちらのカードも移動可能です。

## 集計対象

- **セッション**（デフォルト） — 少なくとも一つの条件に一致するアセントがあるカレンダー上の日（[週あたりのセッション数](/docs/sessions-per-week)と同じ考え方です）
- **アセント** — その曜日のすべての条件に一致するティック

曜日はアセントのUTCにおける `YYYY-MM-DD` 日付から取得されます — ログブックの行は時刻なしの日付のみで記録されています。

## フィルター

- **全期間** / **直近12週間** — 短期間の範囲については、今日を末日とする84日間の期間を含みます
- **セッション** / **アセント** — グラフの扇形の大きさが何を意味するか
- **すべて** / **スポーツ** / **トラッド** / **ボルダー** — スタイルチップは、アプリ内の他の箇所と同じ種目別カラーを使用しており、ログブックのスタイルフィルター（クライミング・スタイル**または**ルート・スタイル）と一致します。トップロープやその他のスタイルは、**すべて**の下にのみ表示されます。

選択内容はブラウザに保存されます（`cs_weekday_range`、`cs_weekday_metric`、`cs_weekday_style`）。

## 最も活動的な曜日

ドーナツグラフの中心と引き出し線には、現在の指標で最高値を示した曜日が表示されます（同値の場合は、もう一方の指標に基づいて決定されます）。該当する曜日のグラフの扇形と凡例の行が強調表示されます。チャート下の**曜日の値を表示**では、スクリーンリーダーやキーボード利用者のために、正確なセッション数、アセント数、およびシェア率をリスト表示します。
