# 年間統計

前年比テーブルには、チャートのメトリクスに関係なく、登攀数とオンサイト数の差が回数として、高度の差が選択した高度単位で常に表示されます。

**年間統計**ダッシュボードカード（および、そのページが有効な場合の\*\*[アクティビティ](/activity)\*\*のチャート）では、ボリュームが年ごとにどのように変化しているかを確認できます。

## 年別

選択したメトリクスの棒グラフ（古い順 → 新しい順）：

- **登攀数** — その年に記録されたすべてのティック
- **完登数** — 成功したティックのみ（[ティックの種類](/docs/tick-types)を参照）
- **高度** — 合計登攀高度（「設定」の好みの高度単位に合わせてメートルまたはフィートで表示）。ティックに高度情報がない場合はルートの高度が使用されます

各棒グラフの下にある小さな数字は、前の暦年と比較した**前年比の差分**です（最初の年は「—」と表示されます）。年ごとの棒グラフは `/logbook?year=` にリンクしています。

## 累計

太いアクセントラインは、選択したメトリクスの**キャリアを通じた累計**を示します。細い色のオーバーレイ（日次ヒートマップデータが利用可能な場合）は、それぞれ一月1日にゼロから再開し、共通の一月〜十二月の軸に沿って日ごとに上昇するため、シーズンを並べて比較できます。その年の最後の登攀の後、細いラインは**十二月まで水平**に継続します（架空のボリュームが生成されることはありません）。細いライン上の日付をクリックすると、その日の `/logbook?day=` が開きます（ホバーするとその年の累計が表示されます）。キャリアドットの下にある括弧内の数値は、別の前年比差分ではなく、**その年の貢献分**です。

チャートモードの設定はブラウザ（`cs_yearly_chart`）に保存されます。

## 前年比テーブル

カードの**前年比テーブル**を展開すると、ログブック内のすべての年について、登攀数、高度、オンサイト数の数値的な差分を確認できます。
