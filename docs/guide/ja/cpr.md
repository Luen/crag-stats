# CPR（クライマー・パフォーマンス・レーティング）

**CPR** は theCrag によるクライミング能力の評価です。これら三つの種目は評価方法が大きく異なるため、theCrag と同様に Crag Stats では**スポート**、**トラッド**、**ボルダー**の CPR タイムラインを個別に表示します。

## theCrag による CPR の計算方法

theCrag は約百万件の完登記録の統計分析に基づいて CPR を構築しました。主なコンセプト:

- **各グレードは、一つ下のグレードよりも約5倍難しくなります**（Ewbank スケールでの累乗係数 _P_ = 5）。完登したユニークなルートごとに、そのグレードの _P_ の乗数が合計に加算されます。その合計値は、底が 5 の対数を用いて再びグレードに変換されます。そのため、あるグレードでの五回の完登は、ひとつ上のグレードでの一回の完登とほぼ同等の価値を持ちます。
- **ティックシフト。** どのように登ったかが重要です。完登記録は、スコア計算の前にグレードオフセットによってシフトされます。たとえば、スポートクライミングではオンサイトよりも約 **2.1 グレード** 高いグレードをレッドポイントでき、トラッドではピンクポイントはレッドポイントより約 **0.8 グレード** 易しくなります。オフセットは、スポート、トラッド、ボルダーでそれぞれ個別に算出されます。
- **グレードの定着。** 新しいグレードでの一回の完登は、甘めのグレード設定のルートや偶然の成功である可能性があります。あなたの_グレード_はそのグレードでの約 **三回** の完登を経て初めて上昇しますが、すべての完登は引き続きレーティングに加算されます。
- **減衰。** クライミングを中断すると、CPR は **年間約 0.7 Ewbank グレード**（およそ四分の三グレード）低下します。
- ルートの**再登**は一回（最高の完登記録）のみカウントされ、個人の感想ではなく設定されたルートのグレードが使用されます。

theCrag は、スポート、トラッド、ボルダーのそれぞれについて、減衰ありと減衰なしのレーティングを保持しています。

## Crag Stats でのデータの取得元

- **theCrag の API から（推奨）。** サポーター API キーで同期すると、各完登記録に theCrag 独自の CPR 値が含まれるようになります。ある種目における完登記録の十分な数（3回以上、かつその種目の全完登記録の20%以上）に CPR 値が含まれている場合、タイムラインには _theCrag CPR_ とラベル付けされた **theCrag の減衰あり CPR** が使用されます。
- **近似モデル（フォールバック）。** そうでない場合、Crag Stats は独自に計算した _Approx._ ラベルの CPR を表示します。これは、_P_ = 5、ルートごとの最高完登記録、ティック・シフト、年間 0.7 グレードの減衰という同じコンセプトを使用します。ティック・シフトは推定値であり、たとえばスポートではオンサイト +2.1、フラッシュ +1.4、レッドポイント 0、ピンクポイント −0.5、トライ −3 となります。 **theCrag の独自実装の完全なコピーではないため**、わずかな差異が生じることがあります。

## タイムラインの読み方

- 各**列**は四半期を表します。
- **ローソク足**は、その四半期に各完登タイプで登ったグレードの範囲を示します。 theCrag と同様に、最も純粋な完登記録が一番上に表示されます：オンサイトは緑、フラッシュは黄、レッドポイントは赤、ピンクポイントはピンク、完登/クリーンは青、トライはグレーです。
- **黒い線**は、あなたの CPR の時系列推移を示しています。二重丸はあなたの**最高値**を、白抜きのドットは**現在**のレーティングを示します。
- **色付きの背景**は、実際のグレード境界におけるグレード帯（ビギナー → エリート）を示しています。
- 下部の**バー**は、その四半期に記録した完登回数を示します。バーをクリックすると、ログブックでそれらの完登記録が開きます。
- 時間軸上の **⋯** が付いた**破線の区切り線**は、一四半期以上の空白期間を示します。
- **空の四半期を表示**を有効にすると、最初の記録と最後の記録の間のすべての四半期に個別の列が割り当てられます。完登記録のない四半期は空のままになり**黒い線が途切れる**ため、長期間のレストが順調な成長として表示されることがなくなります。追加の列により幅が必要な場合、チャートは横にスクロールします。オーストラリア・ニュージーランドで一般的なシステム。ボルダー課題は通常Vスケールを使用します。

theCrag によると、ラインの上にある**グレーの頂部**（より高いグレードでのトライ・失敗記録）は、グレードアップの直前によく見られる傾向があるとされています。
