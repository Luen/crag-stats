# アクティビティ

ダッシュボードの **Monthly stats** カードと **Yearly stats** カードは、登攀ボリュームを一目で把握できるようにまとめたものです。 **Activity**（`/activity`）は、チャート以上の詳細情報を確認したい場合に使用する詳細ページです。月ごとの完全なテーブル（登攀数、完登数、高度、スタイルの内訳）や、前年比の年間内訳が掲載されています。

## 集計対象

- **Ascents** — その日/月/年に記録されたすべてのティック（トライを含む）。
- **Sends** — 完登として分類されたティック（[Tick types](/docs/tick-types) を参照）。
- **Height** — 登攀記録またはルートの高さが存在する場合のメートル数。
- **Styles** — ギアスタイルに基づく Sport / Trad / Boulder。それ以外のスタイルはテーブル上で **Other** にまとめられます。

月リンクをクリックすると、その該当カレンダー月のログブックが開きます。年リンク（年間カード/テーブル上）をクリックすると、`/logbook?year=` が開きます。

## 独立したページになっている理由

同じ二つのチャートだけを繰り返すと、サイドバーが肥大化する原因になります。 Activity ページは、**月別内訳テーブル**を掲載し、前年比の差分を簡単に確認できるようにすることで、単なる簡易カードにとどまらない独自の存在価値を備えています。

## ストリーク

Streaksカードには、通算**最長**日ストリークの横に、現在の「日」「週」「月」のストリークが表示されます（四つのメトリクス タイル）。最長ストリークの開始日と終了日は
タイルの下に表示されます。同一の最長記録が複数存在する場合、最も古い期間が表示されます。単一のクライミング日には一つの日付が表示され、履歴が空の場合は記録日付がありません。

フッターには、最終クライミング日、現在の「日ストリーク」が切れている場合にそれから何日間経過したか、および通算の **active days**（実際にクライミングを行った日数）も表示されます。日数は有効に記録された登攀日付に基づきます。トライと完登、インドアとアウトドアはすべて同等にカウントされ、一日に複数の登攀を行っても一回としてカウントされます。 7日、10日、30日のマイルストーンについては [Badges](/docs/badges) を参照してください。

現在の日ストリークは、今日登っていれば本日まで、今日まだ登っていない場合は昨日までとなります。カレンダー日の比較には UTC が使用されるため、サーバーのタイムゾーンや夏時間の変更によって記録された日がずれることはありません。未来の日付が指定されたエントリーは、現在のストリークを延長しません。

現在の週ストリークおよび月ストリークも同様の猶予ルールに従います。現在の期間で終わる連続期間、あるいは今期まだクライミングを行っていない場合は直前の期間で終わる連続期間をカウントします。まるまる一週間または一ヶ月間実績がない場合、そのカウンターはゼロになります。週は月曜日に始まり、ISO第53週や新年をまたぐ場合を含め、カレンダーの境界にはUTCが使用されます。未来の日付が指定されたエントリーは、これらのカウンターにカウントされません。

## 最近のアクティビティ

ダッシュボードには、最新の**クライミング日**が最初に表示されます。同一日の内では、プロバイダーのログ作成タイムスタンプに基づき、最も最近**記録された**登攀が最初に表示されます。表示される日付はクライミングを行った日付のままです。過去のクライミングを今日記録しても、それより新しいクライミング日の記録より上に移動することはありません。記録順は、順番に登攀を入力する際のクライミング順の代用となるものであり、記録された登攀時刻そのものではありません。

ログ時刻が不足しているか無効なエントリーは、同日の時刻が記録されているエントリーの後に配置されます。ログ時刻が同一または利用できない場合は、順序を安定させるため、新しいものから順に保存された登攀IDが使用されます。編集/同期のタイムスタンプは、ログ作成時刻として使用されません。

最近のアクティビティにも、ログブックと同じクライミングスタイルのバッジが表示されます。ルート種別、適用可能な場合は異なる記録済みプロテクションスタイル、および Lead solo や Top-rope solo などの明示的なソロバリエーションが含まれます。パートナーが記載されていない場合でも、ソロクライミングを意味するわけではありません。
