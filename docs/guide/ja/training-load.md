# トレーニング負荷

**トレーニング負荷**カード（および専用の[`/training-load`](/training-load)ページ）は、身体が慣れている負荷と比較して、最近どれだけハードに登っているかを推定します。急激な負荷の増加は、指や肩の怪我が最も発生しやすいタイミングです。ダッシュボードのカードは直近12週間をまとめ、詳細ページでは26週間分と28日間の日次負荷推移を表示します。

## 1。一登攀あたりの負荷

各登攀には負荷スコアが割り当てられます：

> **負荷 = 10 × 強度 × スタイル係数**

**強度**は、登攀したグレードと、同じ種目における**過去12ヶ月間の最高完登グレード**を比較します。ルートはEwbankグレード、ボルダリングはVグレードで比較されます。

| 過去12ヶ月の最高グレードとの比較                       | 強度    |
| --------------------------------------- | ----- |
| 自己最高グレード                                | 1.0   |
| 2 Ewbankグレード（1 Vグレード）下                  | 0.5   |
| 4 Ewbankグレード（2 Vグレード）下                  | 0.25  |
| 自己最高を更新（ニューハイ）                          | 最大1.5 |
| グレード未設定のルートまたはtheCragのプロジェクト（下記参照）をトライ中 | 1.0   |
| グレード未設定の完登、または過去12ヶ月間に完登なし              | 0.3   |

限界に近い登攀は、余裕のあるグレードを数多くこなすよりも負荷が高くカウントされます。易しいルートを十本登った日と、一つのプロジェクトに費やした日は、同等の負荷になることがあります。

**グレード未設定およびフラグ付きプロジェクト：\*\*\*\*グレードなし**のルート、またはtheCragで**Project**フラグ（オプションのルート情報インポートによる）が付いたルートでのアテンプト、ハングドッグ、その他の未完登の記録は、**限界グレード**での登攀として扱われます。トライし続けているグレード未設定のルートは、通常、限界に近い新しいラインです。フラグがある場合は、それが確定的なケースとなります。これらのアテンプトは「限界に近い登攀の割合」にもカウントされます。 theCrag上で自分でその記録にグレードを付けた場合は、そのグレードが優先されます。グレード未設定の完登 _send_ は、名前のない易しいルートが限界グレードの日のように見えないよう、低い負荷 (0.3) としてカウントされます。

\*\*スタイル係数：\*\*リードでの完登は1.0です。アテンプトやハングドッグは0.8です。ルートの攻略も実際の労力を伴うためです。トップロープやセカンドでの登攀は、さらに0.8倍されます。

## 2。疲労とフィットネス

日次負荷は二つの方法で平均化され、どちらも直近の日数に重みが置かれます：

- \*\*疲労（急性）：\*\*7日間の指数加重平均。
- \*\*フィットネス（慢性）：\*\*28日間の指数加重平均。

## 3。急性・慢性負荷比

**比率 = 疲労 ÷ フィットネス**

| 比率        | ステータス    | 意味                                  |
| --------- | -------- | ----------------------------------- |
| —         | 休養中      | 最近ログがありません                          |
| < 0.8     | 通常以下     | 通常より軽い：フレッシュな状態、テーパリング、またはフィットネスの低下 |
| 0.8 – 1.3 | スイートスポット | 身体が慣れている範囲内                         |
| 1.3 – 1.5 | 負荷上昇中    | 通常より多く登っています。リカバリーに注意してください         |
| > 1.5     | 急増       | 急激な負荷の増加。使いすぎによる怪我に最も関連するゾーンです      |

これらの数値帯は、スポーツ科学やクライミングのコーチングで使用される急性・慢性負荷比に基づいています。これらは診断ではなく、あくまで目安として扱ってください。

## カード・ページ内のその他の項目

- \*\*週次負荷：\*\*各週の合計負荷（カードでは12週間、ページでは26週間）。今週分はハイライトされたバーで表示されます。
- **日次負荷 (ページ):** 直近28日間の強度加重負荷、休息日を含む。
- **限界に近い完登 · 28d:** 過去12ヶ月の最高グレードから2 Ewbankグレード (1 Vグレード) 以内の、直近28日間の完登数。
- \*\*限界に近い割合：\*\*直近28日間のグレード付き登攀のうち、限界に近いグレードが占める割合。数週間にわたりこの割合が高い場合は、限界の登攀が多いことを意味します。ディロード週を検討してください。
- \*\*過去 7 / 28 日間：\*\*登攀数、完登数、登った日数と休息日数、登攀高度、完登率。

## 注意事項

- \*\*ログに記録されたものだけがカウントされます。\*\*ジムでのセッションや指ボードなど、ログに残さないトレーニングは反映されません。
- **グレードにはばらつきがあり**、お買い得なルートや逆にお買い損なルートは強度を歪める可能性があります。
- \*\*比率の算出には履歴が必要です。\*\*ログが数週間分に満たない場合、「フィットネス」が低く算出され、比率が不安定になります。

プロジェクトルートの場合、個人のグレードは登攀記録または登ったピッチ（あるいはCSVのAscent Gradeフィールド）から取得される必要があります。ルートからコピーされた有効グレードはあくまで予備であり、プロジェクトを「限界グレード」と見なす想定を無効にするものではありません。
