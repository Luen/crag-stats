# 表示設定

**設定 → 表示と公開範囲**では、サイト全体での日付と測定単位の表示方法を設定します。この設定は所有者のブラウザだけでなく、すべての訪問者に適用され、次回のページ読み込み時から有効になります。

## 日付形式

| オプション          | 例          |
| -------------- | ---------- |
| **自動**         | 2026年十月27日 |
| **DD/MM/YYYY** | 27/10/2026 |
| **MM/DD/YYYY** | 10/27/2026 |
| **YYYY-MM-DD** | 2026-10-27 |

**自動**はサイトの表示ロケール（`DISPLAY_LOCALE`）に従うため、追加の設定なしで多くの訪問者にとって自然な表示になります。

この形式は、ダッシュボード、ログブック、天候ページ、バッジ、目標、マイルストーン、チャートに表示されるカレンダーの日付を変更します。フィルターのリンク、`datetime`属性、チャートデータ、URLパラメータはISO形式の`YYYY-MM-DD`値を保持するため、共有リンクは常に同じ日付を指し示します。

## 測定単位

各測定項目に個別の設定があるため、自由に組み合わせることができます：

| 測定項目    | 選択肢                  |
| ------- | -------------------- |
| **高さ**  | メートル (m)、フィート (ft)   |
| **距離**  | キロメートル (km)、マイル (mi) |
| **気温**  | 摂氏 (°C)、華氏 (°F)      |
| **風速**  | km/h, mph            |
| **降水量** | ミリメートル (mm)、インチ (in) |

プリセットを使用すると、五つの項目すべてを一度に設定できます：

- **メートル法**: メートル、キロメートル、摂氏、km/h、ミリメートル。
- **ヤード・ポンド法（米国）**: フィート、マイル、華氏、mph、インチ。
- **英国（混合）**: メートル、マイル、摂氏、mph、ミリメートル。

プリセットはショートカットに過ぎません。適用後に個別の単位を変更してカスタム構成にすることができ、設定フォームには保存されている値が表示されます。

## メートル法のまま維持される項目

データベースには常に、高さはメートル、距離はキロメートル、気温は°C、風速はkm/h、降水量はミリメートルで保存されます。単位の変換はページがレンダリングされる際にのみ行われるため、単位を切り替えてもログブック、目標、インポートデータが書き換えられることはありません。

- **CSVエクスポート**では、標準のメートル法カラムが維持されます。
- **バッジのしきい値**（登攀高度、猛暑、凍結、降雨、強風など）は、メートル法で定義されています。表示上の表記のみが変換されます。例えば、**Heat Wave**はメートル法では「35°C以上」、華氏では「95°F以上」と表示されます。どちらの表示単位であっても、同じクライミング記録に対して同じバッジが獲得できます。
- ログブックの猛暑、凍結、雨、雪、風などの**天候フィルター**は、メートル法のしきい値を維持します。
- **単位変換は表示用に四捨五入**されるため、フィート、マイル、インチで表示される値は、データベースに別途保存された値ではなく概算値となります。

## 一時的なオーバーライド

ダッシュボードでは、`?units=metric`、`?units=imperial`、`?units=uk`を使用して、設定を保存せずにプリセットをプレビューできます。個別のパラメータを使用して、測定項目を一つずつ上書きすることもできます：`unitHeight`、`unitDistance`、`unitTemp`、`unitWind`、`unitPrecip` (例：`?unitTemp=fahrenheit&unitWind=mph`)。これらはそのページの読み込み時にのみ適用され、設定自体は変更されません。

## 設定が適用される場所

日付や単位の選択は、ダッシュボード、ログブック、アクティビティカレンダー、トレーニングロード、天候ページ、エリアやセクター、クライミングマップ、目標、バッジ、マイルストーン、埋め込みカード、オフラインスナップショットに反映されます。グレードシステムは別設定です。[グレード](/docs/grades) を参照してください。
