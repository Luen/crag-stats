# クライミングストーリー

**クライミングストーリー**カードは、ログブックをダッシュボード上の短い一人称形式の概要テキストに変換します。デフォルトでは上部付近の**最近のアクティビティ**の横に配置されますが、ダッシュボードのカスタマイズでどちらのカードも移動できます。これはローカル統計から生成された解釈的な文章であり、編集可能な二つ目のログブックではありません。また、非公開の完登メモが含まれることはありません。

## 常に表示される項目

最初の登攀記録日がある場合：

1. クライミング歴の長さとアクティブな日数。
2. 登破数、完登数、オンサイト数、ルート数、エリア数（アカウント同期で提供されている場合はインドア/アウトドアも含む）。
3. 高度が分かっている場合の、エベレストやエル・キャピタンに例えた登破高度。
4. アクティブ日あたりの登破数。
5. クライマーのタイプ、およびオンサイト/フラッシュ派かレッドポイント/トライ派か（他と同様の55%過半数ルールを適用）。

## オプショナルな文章（シグナルが強い場合のみ）

優先順位に従って最大**三つ**の追加の文章が選ばれます。カード全体が概ね5〜7段落に収まるよう、僅差の場合やサンプル数が極めて少ない場合はスキップされます。

| シグナル              | 例                                                                                                                                         | 判定条件（概算）                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 開拓したルート           | 「ボルトを打ってスポーツルートを開拓するのが好きです — 他のクライマーが登り続ける超クラシックルートです。これまでに18本の初登ルートを開拓しました。自分が開拓した中で最も人気のルートは Sample Classic で、120回以上登られている超クラシックルートです！」 | スタイルの優先順位 **スポーツ → トラッド → ボルダー**。明確な開拓数が必要です。コミュニティの**他者**データが存在するルートが2本以上ある場合：他者数が5以下で55%以上の割合 → マイナー/アドベンチャールート。他者数が50以上で55%以上の割合 → 超クラシックルート（集計による「N回以上登られた」の文章を置き換えます）。それ以外の場合、該当スタイルの他者数が10以上のときは集計値を維持します。判明している場合は最も登られている開拓ルート名を常に表示します。超クラシックルートの文章には、そのルートの他者数が100以上の場合にフォーマットされたコミュニティ登破推定数が含まれます。カウントは登破数の推定値であり、ユニーク人数ではありません。 |

| パートナー             | 「アレックスとよく登ります。」                                                                                                                           | 該当するパートナーがタグ付けされた登破記録が十分にある場合。                                                                                                                                                                                                                                                                                                              |

ルートの開拓表示には、キャッシュされたルート履歴のFA/FFAマークおよびセッタークレジットが使用されます。スポーツルートの表現は「スポーツルートを開拓する」、トラッドは「トラッドルートを開拓する」となります。ボルダーは開拓が容易なため、スポーツやトラッドの記録が少ない場合にのみ選択されます。マイナーか超クラシックかのニュアンスおよび最も人気の開拓ルートの文章には、初登カードと同じコミュニティの**他者**スナップショットが使用されます。

最も人気の開拓ルート名は、対応する theCrag ルートページへリンクします。カウントは、初登機能で使用されるキャッシュされた**他クライマーの登破推定数**（所有者自身の対となる登破スナップショットを除く）であり、リアルタイムのカウントやユニーク人数ではありません。これはお使いの数値表示ロケールに従います。キャッシュされたリンクが存在しないか安全でない場合は、利用可能であれば正則な theCrag ルートIDが使用されます。そうでない場合、名前はプレーンテキストのままになります。ストーリーを閲覧しても、プロバイダーへのリクエストは発生しません。

## この機能に含まれないもの

- CPR、カルマ、リーダーボードでの自慢ではありません。
- LLMによって生成されたものではありません — テンプレートのみを使用しているため、同じ統計情報を持つ二つの環境では同じ文章が生成されます。
- メモはログブック上でのみ所有者に限定して保持され、ここに表示されることはありません。
