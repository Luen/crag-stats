# Karma

theCragでは、クライミングインデックスへの貢献、すなわち登攀の記録やトポ・ガイドブックデータの編集に対して**Karma**が付与されます。 [theCragのKarmaについて](https://www.thecrag.com/article/cragkarma)をご覧ください。

## Crag Statsで表示できる内容

サポーター用**logbook** APIのアカウントオブジェクトには、個人のKarma合計や登攀/編集の内訳は含まれて**いません**。エリアの `/karma` エンドポイントはエリアの貢献者リーダーボードであり、個人のアカウントスコアの代わりになるものではありません。

theCragが個人のKarma（または協定されたアクセス権）を公開するまで、ダッシュボードのカードは**登攀部分のみの概算**となります：

| ソース                  | ポイント                                                    |
| -------------------- | ------------------------------------------------------- |
| 登攀の記録                | ルート (ノード) ごとに一回あたり**1**ポイント、theCragの貢献タイプごとに一回というルールに準拠 |
| ガイドの編集（詳細説明、トポ、履歴など） | **利用不可** — logbookキャッシュから再構築できません                       |

同期されたアカウントに `routesTicked` が含まれており、その数値がローカルのルートキャッシュ以上である場合、カードはその数値を登攀の合計として使用します（これはtheCragの「登攀を記録したルート数」と一致します）。それ以外の場合は、ローカルのSQLiteキャッシュ内にある重複のないルート数をカウントします。

**記録されたローカルルート**のタイルには、登攀推計値がアカウントの大きい方のカウンターを使用している場合でも、キャッシュされた登攀にリンクされている重複のないルート数が常に表示されます。再登は一回としてカウントされ、登攀記録のないルートメタデータはカウントされません。

## 注意点・該当しないもの

- theCragプロフィール上のスコアと完全に一致する複製ではありません。
- 実際のKarmaはアカウントに反映される前に、約一週間**審査キュー**に入ります。
- 登攀の削除や編集、非公開アカウント、過去データのインポートなどにより、ローカルのカウントとtheCragの間で同期のずれが生じることがあります。
- 初登のマークやルートセッターのクレジットから編集ポイントを独自に生成することは**ありません**。これらのアクティビティはtheCragでKarmaを獲得できる場合がありますが、採点ルールは貢献タイプごとにノードあたり一回であり、アプリ側には編集履歴が保持されていないためです。

## 今後の改善可能性

theCragがlogbookアカウントのペイロードや安全に同期可能なドキュメント化されたクライマー用エンドポイントにKarma（または登攀/編集の合計）を追加した場合、Crag Statsは推計値を実際の数値に置き換え、編集タイルを更新することができます。
