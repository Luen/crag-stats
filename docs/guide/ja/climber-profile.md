# クライマープロファイル

**クライマープロファイル**のレーダーチャートは、**過去30日間**（内側の系列）と**過去90日間**（外側の系列）のクライミング状況を比較します。各軸はローカルログブックに基づいて 0–100 でスコア化され、theCragのリーダーボードスコアではありません。

## 評価軸

| 軸            | 評価対象                                         |
| ------------ | -------------------------------------------- |
| **ボリューム**    | 対象期間に対して記録したアセントの数。                          |
| **スタイルの多様性** | 記録されたクライミングスタイルの種類（ルート、トラッド、ボルダーなど）。         |
| **密度**       | 対象期間に対して実際にクライミングを行った日数。                     |
| **高度**       | 対象期間中に登ったメートル数（アセントまたはルートの高度）。               |
| **強度**       | 対象期間中の平均グレードおよび最高実効グレード（より難しい完登記録で数値が上昇します）。 |
| **一貫性**      | 完登率とオンサイト/フラッシュ率の組み合わせ — 完登および一発完登の記録。       |

スコアは最大100点に制限されます。レスト期間中は各軸が内側に縮み、アクティブなツアーやプロジェクト集中期間には外側に広がります。レーダーの形状は診断結果ではなく、傾向のアドバイスとして捉えてください。

## 30日と90日の比較の見方

- **過去90日間**（ティール色の塗りつぶし）は、最近のベースラインを示します。
- **過去30日間**（青い枠線）は、直近の月が各軸でそのベースラインを上回っているか下回っているかを示します。

どちらかの多角形が表示されない場合、その期間に十分な日付付きのアセント記録がまだありません。
