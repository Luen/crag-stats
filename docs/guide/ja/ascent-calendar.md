# アセントカレンダー

**アセントカレンダー**は、クライミングを記録した日々の年間ヒートマップです。各セルはその日付の`/logbook?day=`へリンクしています。

## インテンシティ

色はその日に記録された完登数に応じてグラデーション変化し（なし → 少ない → 多い）、他と同様の緑のヒートマップスケールを使用します。トライ数もインテンシティにカウントされますが、ツールチップでは完登数が区別されて表示されます。

## グレード

各日付は、その日の**最高難易度の完登**に基づいて色分けされ、他の場所のグレードチップと同じ「ビギナー → エリート」のバンドパレットが使用されます。トライのみ（完登なし）の日には、控えめな「トライ」の塗りつぶしが使用されます。同じ日にボルダーとルートのグレードが混在している場合、カレンダーはより高いバンドIDを選択します — バンドは体系間で完全に比較できるわけではありません。

インテンシティ / グレードの設定はブラウザに保存されます（`cs_heatmap_mode`）。

## 天候

オプトインの[天気キャッシュ](/docs/weather)にクライミングを行った日が含まれている場合、第三の**Weather**モードが表示されます。クライミングを行った各日は、キャッシュされた天気データが存在するその日最初の屋外完登時のコンディション: 雪、雨、猛暑 (35°C+)、氷点下、快適 (15–25°Cかつ乾燥)、または穏やかに応じて、バッジと同じルールで色分けされます。キャッシュされた天気データがない日（インドアジム、座標なし、未取得など）は、控えめなグレーのまま表示されます。ツールチップには最高気温、最低気温、降水量が一覧表示され、カレンダー下の**天候データを見る**テーブルには、選択した年の同じ数値がテキストとして表示されます。

カレンダーのセルは、サマータイムの変更を含め、すべてのブラウザタイムゾーンで記録されたカレンダー日付を維持します。クライミングを行った日をローカルのタイムスタンプに変換することはありません。
