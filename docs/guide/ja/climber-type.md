# クライマータイプ

ダッシュボードには、_スポーツクライマー_や_ロッククライマー_などの**クライマータイプ**のラベルが表示されます。これはダッシュボードの上部と「クライマータイプ」カード内に配置されています。

## 判定方法

1. **すべての記録タイプをカウントしている間は theCrag を優先。** theCrag アカウントにクライマータイプが設定されている場合（API経由で同期）、Crag Stats はそれをそのまま使用します。設定で記録タイプを_プロジェクトと目標のみ_または_非表示_に変更すると、ラベルはカウント対象の登攀記録から再計算されます。これにより、プロジェクトのトライによって誤ったジャンルに分類され続けるのを防ぎます。
2. **それ以外の場合はログブックから計算。** カウント対象のすべての登攀記録は、そのジャンル（ギアスタイル）にカウントされます：スポーツ、トラッド、ボルダリング、トップロープ、アルパイン、エイド、ディープウォーターソロなど。デフォルトではトライもカウントされますが、設定で[カウント対象の記録タイプ](/docs/tick-types)をカスタマイズすることで、プロジェクトへのトライ（ボルダー課題の打ち込みなど）によってクライマータイプが歪められるのを防ぐことができます。
3. **40% ルール。** 単一のジャンルがカウント対象の全登攀記録の**少なくとも40%**を占めており、_かつ_そのジャンルが**スポーツ、トラッド、またはボルダリング**である場合、あなたは「スポーツクライマー」、「トラッドクライマー」、または「ボルダークライマー」となります。
4. **それ以外はすべて** **ロッククライマー** となります。これには、どのジャンルも40%に達していない場合や、最も割合が高いのがトップロープなどである場合が含まれます。

カード内のカラーバーは、他の場所と同じ色を使用して各ジャンルの割合を示しています：スポーツは青、トラッドはオレンジ、ボルダリングは赤。

## なぜ40%なのか？

多くのクライマーは複数のジャンルを並行して行います。 50%を大幅に下回る閾値であっても、オールラウンダーを単一の枠にはめ込むことなく、明確な好み（例えばスポーツ47%、ボルダー24%、トラッド24%）を捉えることができます。各スタイルに満遍なく時間を割いているクライマーは「ロッククライマー」のままとなります。

## 変更方法

- theCrag プロフィールでクライマータイプを設定して同期する、
- プロジェクトへのトライによってジャンルの割合が偏っている場合は、設定でカウント対象の記録タイプを調整する、または
- 自分がメインだと感じているスタイルの記録をより多く登録する。ラベルは次回のページ読み込み時に更新されます。
